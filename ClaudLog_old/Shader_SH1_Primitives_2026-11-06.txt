■ 作った物
  プリミティブ 8 種 : Cube / Sphere / Capsule / Cylinder / Cone / Torus / Plane / Quad
    大きさは Unity と同じ : 立方体 1 / 球 直径 1 / カプセル・円柱 直径 1 × 高さ 2 / 円錐 直径 1 × 高さ 1 / トーラス 外径 1 (輪 0.35 + 管 0.15) /
    平面 10 × 10 (上向き、10 分割) / クアッド 1 × 1 (-Z 向き)。どれも原点が中心。UV / 法線付き (立方体と円柱のふたは角で法線を分ける)
  モデルのパス : "builtin:Cube" / 分割数を指定 "builtin:Sphere:64" (3〜256)。ファイルは作らない
    engine.Assets.LoadModel("builtin:Torus") / engine.Assets.LoadPrimitive(PrimitiveShape.Torus) で読める。同じパスは同じ Model
    シーンにはこのパスで保存 (Id 無し)。書き出したゲームも同じ形をその場で作る (書き出しの依存の探索は注意を出さない)
  エディター : GameObject > 3D Object > 8 種 (カメラの 5 m 前。Shift を押しながら選ぶと選んでいる物の子) /
    Hierarchy の右クリック > Create 3D Object Child。元に戻せる
    形に合うコライダーも付ける : 立方体 Box / 球 Sphere / カプセル・円柱 Capsule (Unity と同じ) / 平面・クアッド 薄い Box /
    円錐・トーラス Mesh (メッシュのコライダーは動かない物用)
  SH3 の雲は、この Cube に雲のマテリアルを付けて描く

■ 仕組み
  C++ (Renderer) : SceneRenderer::CreateMesh / Renderer_CreateMesh (新規)
    頂点 (RHI::Vertex 56 byte) とインデックスの配列 → メガバッファに登録、白い不透明のマテリアル、サブメッシュ 1 つ。
    衝突判定のメッシュ用の形も残す。名前 (builtin:...) をモデルの Path にする (空でない = 使っている番号)。番号は LoadModel と同じく使い回す
  C# : Assets/Primitives.cs (新規。形を作る / パスの読み書き / 形に合うコライダー) / AssetManager.LoadModel が builtin: を見て作る
  面の向き : このエンジンは画面で時計回りが表。三角形は、頂点の法線 (外向き) の側から見て時計回りになるよう、作る時に並びを直す
    (左手系で cross(b - a, c - a) が外を向く)。見た目で 8 種とも表が外 (影 / ライティングが正しい) を確かめた
