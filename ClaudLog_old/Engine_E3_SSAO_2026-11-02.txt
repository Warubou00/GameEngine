====================================================================
 エンジン化 E3 (2/3) : SSAO (スクリーンスペース・アンビエントオクルージョン)
 日付   : 2026-11-02
 ブランチ : feature/e3-ssao
====================================================================

■ 概要
  - SSAO をポストエフェクトとして追加した。Forward / Deferred のどちらでも使え、実行中に ON / OFF できる (F4)
  - 遮蔽は「環境光」にだけ掛ける (ライトの直接の光には掛けない)。Forward でも深度のプリパス無しで正しく分けた
  - 確認用に、遮蔽だけを白黒で出す表示を付けた (F5)
  - 見本のシーンに地面を置いた (物が接する所に遮蔽が出ることを見るため)
  - 法線の変換を直した (不均一なスケールで法線が傾いていた。下記)

■ 仕組み
  C# の SsaoPass (Forward / Deferred 共通の部品)
    1. PSSsao     : 深度 (+ 法線) → 遮蔽 (R8)。解像度は画面の半分が既定 (SsaoSettings.ResolutionScale)
    2. PSSsaoBlur : 横 → 縦にぼかす (9 タップ。深度の違う所はまたがない)
  Deferred : G-Buffer の法線を使う。ライティング (PSDeferredLighting) が遮蔽を読み、環境光に掛ける
             (遮蔽を渡さない時は既定テクスチャの白 = 遮蔽なし を読むので、シェーダーの分岐は要らない)
  Forward  : 物を描く時に「ライトの光 (HDR)」と「環境光 (R11G11B10F)」を 2 枚に分けて書き (PSForwardSplit)、
             深度から遮蔽を求めて、「環境光 × 遮蔽」を HDR に足す (PSApplyAmbient。加算のブレンド)
             → 遮蔽が環境光にだけ掛かる。深度だけを先に描く (プリパス) も要らない
             (プリパスにすると不透明を 2 回描くことになり、1 フレーム 1 回の GPU カリングと合わない)
             法線は深度から作る (左右・上下の近い方の隣を使い、物の縁で混ざらないようにする)

  遮蔽の求め方
    - 法線の向きの半球の中に点を置き (黄金角のらせん。cos で重み付け)、点を画面に投影して、
      そこの深度の物より奥なら「遮られている」と数える。半径より遠く離れた物は数えない
    - 点の並べ方を 4x4 ピクセルごとに回し (Bayer)、ぼかしで模様を消す
    - パラメータ (Graphics.Ssao) : Radius 0.6 / Intensity 1.5 / Bias 0.02 / SampleCount 12 / ResolutionScale 0.5 / ShowOnly

■ RHI / シェーダーの変更
  - ScenePass.ForwardSplitAmbient (PSForwardSplit)、RenderTargetFormat.R11G11B10F を追加
  - hlslTemplate.shader : shade を shadeAmbient (環境光) と shadeLights (ライト) に分けた
                          shade(..., ao) = 環境光 × ao + ライト
  - ssao.shader (新規) : PSSsao / PSSsaoBlur / PSApplyAmbient / PSShowAo

■ 法線の変換の修正 (hlslTemplate.shader VSMain)
  - 法線をワールド行列でそのまま変換していたため、不均一なスケール (地面のように箱を平たく伸ばした物) で
    法線が傾いていた。箱の角の面取りが、ほぼ水平なのに横向きの法線になり、
    Deferred の SSAO で地面の縁が黒い帯になった (ライティングも崩れていた)
  - ワールド行列の余因子行列で変換するようにした (= 逆転置行列 × 行列式。逆行列を求めなくてよく、外積 3 回)
    (以前のコメントにあった「不均一スケールを使うようになったら逆転置行列に変えること」の対応)

■ 高速化 (計測して決めたこと)
  RTX 2070 / Release / 1280x720 / GPU 時間 (ms)。見本のシーン (地面あり) / PBR
                                         SSAO なし   SSAO (半分の解像度・既定)   SSAO (等倍)
    Forward                              0.239       0.337 (+0.10)               0.511 (+0.27)
    Deferred                             0.261       0.334 (+0.07)               0.505 (+0.24)
    負荷テスト 20002 個 (Forward)        0.266       0.339 (+0.07)               -
    点の数 (半分の解像度) : 8 点 0.328 / 12 点 0.337 / 16 点 0.348

  1. 点ごとの計算をビュー空間にした
     以前 (最初の実装) はワールド空間で、点ごとに View と Projection の 4x4 行列を掛けていた。
     ビュー空間なら投影は「x, y に倍率を掛けて z で割る」だけ。点ごとの sin / cos も回転の掛け算に替えた
     等倍 12 点 : +0.30 → +0.26 ms。残りは点ごとの深度の読み込み (画面のあちこちを読むのでキャッシュが効きにくい)
  2. 遮蔽は画面の半分の解像度で求める (既定)
     読み込みが 1/4 になり +0.26 → +0.10 ms。見た目の差はほとんど無い (縁が少しぼやける)
     最初は斜めに見える地面に横縞が出た : 縮小したバッファのピクセルの中心が深度のピクセルの境目に来て、
     読んだ深度と位置がずれていたため。深度のピクセルの中心に合わせて直した
  3. Forward は環境光を R11G11B10F (4 byte) に分けて書く (RGBA16F の半分)。SSAO を切るとこの分も無くなる
  4. ぼかしの 1 歩の長さはシェーダーがテクスチャの大きさから求める (C# は画面の大きさを知らなくてよい)

■ 確認
  - Debug (D3D12 デバッグレイヤー有効) で D3D12 のエラー / 警告 0
      Forward / Deferred の SSAO (半分 / 等倍)、負荷テスト ground (Deferred)、ウィンドウのリサイズ、
      F2 (Forward ⇔ Deferred)・F3・F4 (SSAO の ON / OFF)・F5 (遮蔽だけ表示) の切り替え
  - 遮蔽だけの表示 (F5) で、箱・岩の地面との境目に遮蔽が出ることを確認。Forward (深度から法線) と Deferred (G-Buffer の法線) でほぼ同じ
  - Unlit では SSAO を使わない (環境光が無いため)

■ 制限 / 次
  - 半透明の物には遮蔽が掛からず、遮蔽を作る物にもならない (SSAO の時点では半透明をまだ描いていないため)。
    PMX のキャラクターは材質が全部「半透明」なので、今は遮蔽が出ない
    (不透明として描ける材質を見分ける / 半透明でも深度だけ先に書く、などで対応できる)
  - ③ アンチエイリアス (FXAA = ポストエフェクト / MSAA = 固定機能。切り替え可能)
