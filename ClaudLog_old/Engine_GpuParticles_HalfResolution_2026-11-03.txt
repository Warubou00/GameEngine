GPU パーティクル : 縮小バッファ (半分の解像度) で描く (2026-11-03)
==========================================================================
前 : ClaudLog/Engine_GpuParticles_DrawOptimization_2026-11-03.txt
     (煙を近くから見る場面で、描画が 1.3〜1.6 ms。ピクセルの計算ではなく、塗りつぶしと半透明の重ね描きが重い)
環境 : RTX 2070 / 1280x720 / Release。フレームの GPU = プロファイラーの Summary (縮小バッファを消す / 重ねるパスも含む)

--------------------------------------------------------------------------
1. 仕組み
--------------------------------------------------------------------------
 - RenderPipeline.DrawParticles (Forward / Deferred 共通) :
     縮小バッファ (RGBA16F、画面の 0.5 倍) を 0 で消す → パーティクルを描く → HDR へ全画面のパスで重ねる
 - 縮小バッファの中身 : rgb = 乗算済みの色の合計 / a = 覆った割合。パーティクルの PSO (色 ONE / INV_SRC_ALPHA、α も同じ) のままで、
   a は 1 - (透けて見える割合の積) になる
 - 重ねる : postProcess.shader の PSParticleComposite (線形補間で拡大) を、新しい合成方法 FullscreenBlend.Premultiplied
   (色 + HDR × (1 - a)) で。HDR に直接描いた時と同じ式
 - 深度 : パーティクルのシェーダーは、縮小した位置 × 倍率 で元の画面のピクセルの深度を読む (2x2 の中の 1 つ)。
   倍率は C++ が描画先と深度の大きさから決める (g_Params[0].y。全解像度なら 1)。MSAA の時も 1 サンプルへ解決した深度を読む
 - 設定 : Graphics.Particles.HalfResolution (既定 true)。見本は H キー、起動引数 --particle-half on|off

--------------------------------------------------------------------------
2. 結果 (フレームの GPU。2 回ずつ)
--------------------------------------------------------------------------
  場面                                       全解像度              半分の解像度
  --scene particles --view smoke (煙が近い)   1.257 / 1.477 ms      0.773 / 0.780 ms  (パーティクルの描画 1.39〜1.57 → 0.34 ms)
  --scene particles (見本の全体)               0.838 / 0.843 ms      0.765 / 0.767 ms
  --scene particles --view fountain            0.824 / 0.827 ms      0.742 / 0.742 ms
  --particle-bench 1 万                        0.372 ms              0.393 ms   (縮小バッファを消す / 重ねるパスの固定費 約 0.02 ms)
  --particle-bench 10 万                       0.628 ms              0.641 ms
  --particle-bench 100 万                      2.035 ms              1.758 ms
  - 少ない数では固定費の分だけ遅いが、大きな煙など塗りつぶしの多い場面の差の方がずっと大きいので、既定を半分の解像度にした
  - プロファイラーの GPU particles draw (ms) はパーティクルの描画だけ (消す / 重ねるパスは含まない)

5. 変えたファイル
--------------------------------------------------------------------------
 - RHI/Source/Shader/particleDraw.shader : 深度を読む位置 (縮小の倍率)
 - RHI/Source/Shader/postProcess.shader : PSParticleComposite

 - RHI/Source/DirectX12/RHIObject/CommandContext_Particles.cpp : g_Params[0].y (深度の倍率)
 - C# : FullscreenBlend.Premultiplied / ParticleSettings.HalfResolution / RenderPipeline.DrawParticles (縮小バッファ) /
        見本の H キー・--particle-half

6. 次の候補
--------------------------------------------------------------------------
 - エミッターごとに全解像度 / 半分を選ぶ (細かい火花は全解像度、煙は半分。ただし 2 つに分けると両者の前後の重なりは正しくなくなる)
 - 縁を厳密にするなら、縮小した深度 (2x2 の一番奥 / 手前) を作り、重ねる時に深度の近い所を選んで拡大する (近い深度での拡大)
