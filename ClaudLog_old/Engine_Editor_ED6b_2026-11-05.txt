ブランチ : feature/editor-ed6b

■ 入力のアクション (ProjectSettings の InputActions / InputAxes。Edit > Project Settings)
  ゲームのコードは名前で読む : InputActions.Get / GetDown / GetUp("Jump")、InputActions.GetAxis("Horizontal") (-1〜1)
  アクション = 名前 + キーの並び + ゲームパッドのボタンの並び (どれかを押していれば true)
  軸 = 名前 + キー (+ / - と予備の + / -) + ゲームパッドの軸 (遊び DeadZone、反転)。キーとパッドの大きい方
  既定 : Jump (Space / A) / Fire (Enter / RT) / Cancel (Escape / B) / Horizontal (D A ← → / 左スティック X) / Vertical (W S ↑ ↓ / 左スティック Y)
  ProjectSettings.json には列挙を名前で書く ("Space" など。以前の数値より読める)。知らない名前は false / 0 (1 回だけ Console に出す)
  エンジンの起動時に既定の割り当てを入れる (ProjectSettings を読まない見本でも使える)
  インスペクターの配列 : 「+ Add」で足す / 項目を右クリック → Remove で消す (以前は配列の長さを変えられなかった)

■ 音
  AudioListener (新規コンポーネント) : 聞く位置 (この Transform。無ければカメラの位置) と全体の音量 (Volume)
  AudioSource.Spatial / MinDistance / MaxDistance : 聞く位置からの距離で音量を下げる (Min まではそのまま、Max で 0)。左右の変化は無い (Audio.dll に無い)
  ※音のファイルが手元に無いので、鳴らして耳では確かめていない (コンパイルと、音の無い見本が動くことだけ)

■ カメラ / 音の部品 : Camera / FreeCamera / OrbitCamera / AudioSource / AudioListener に分類 (Camera / Audio) を付け、コンポーネントを足すメニューで分かれて出る
  (FreeCameraSystem / OrbitCameraSystem は以前からエンジン組み込み。付けるだけで動く)

■ 確認用の表示 (エディターの View > Debug Display。シーンには保存しない)
  Colliders / Contacts / Joints (新規 : ジョイントだけを出す。以前はコライダーと一緒にしか出せなかった) / Shadow Cascades / SSAO Only
  Stats にパーティクルの数 (生きている / 描いた / エミッター)

■ 見本をシーンのファイルから (GameEngine_console)
  既定 / --scene physics / --scene particles は、CSharp_console/Project/Assets/Scenes/*.scene.json から読む
  (プロジェクトの Assets/Models がある時。--view を付けた時 / 計測 (--stress など) / --code-scene on の時はコードで作る)
  - 見本を動かす System (Spin / 周回 / レーザー / 物理の操作 / 花火 など) はゲームのコードとしてそのまま (--load-scene と同じ仕組み)
  - プロジェクトがあれば、見本のモデルのパス (../Model/...) も Assets/Models/... に読み替える (シーンのファイルと同じモデル)
  - 物理の見本の R (積み木を作り直す) : 積み木に StackBlock を付けて見分けるように直した
    (以前は作った物を static の一覧で覚えていたので、ファイルから読んだシーンでは消せず、積み木が増えていた)。physics.scene.json を作り直した
  - エディターの再生でも、花火 / 光の群れ (FireworkSystem / FlyerSystem) が動くように登録した (ED7 でゲームの DLL から自動に)
  - 見本のシーンには RenderSettings を入れていない (入れると見本の起動の引数 --pipeline などが最初のフレームで上書きされるため)
