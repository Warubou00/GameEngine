====================================================================
 描画数の詰め直し (GPU カリング後に、映った描画だけを ExecuteIndirect に渡す)
 日付   : 2026-11-02
 ブランチ : feature/draw-compaction
====================================================================

■ 概要
  前回の GPU カリングでは、映らなかった描画も InstanceCount = 0 のまま ExecuteIndirect に全部渡していた
  (GPU が 1 個ずつ読んで、何も描かずに飛ばす)。
  カリングの後にもう 1 回コンピュートシェーダーを実行し、1 個でも映った描画の引数だけを前から詰めて並べ、
  その数を GPU 上で数えて ExecuteIndirect の Count バッファとして渡すようにした。CPU は結果を待たない。

■ 流れ (CommandContext::recordCulling)
  1. CSClear   : 描画ごとの引数を写して InstanceCount = 0。カウンター 2 個 (映ったオブジェクト数 / 詰めた描画数) を 0 に
  2. CSCull    : 視錐台カリング (前回と同じ)
  3. UAV バリア → CSCompact : 1 スレッド = 描画 1 回分。InstanceCount > 0 の描画だけを、詰めた引数の領域に並べる
  4. Culled を INDIRECT_ARGUMENT などの状態へ移し、カウンター 2 個を読み戻し用にコピー
  5. ExecuteIndirect(シグネチャ, 上限 = 描画数, 詰めた引数, Count バッファ = 詰めた描画数)

  CSCompact の並べ方 :
    - グループ (64 描画) の中では元の順番を保つ (groupshared で前にある「映った描画」の数を数えて書き込み位置を決める)。
    - グループの書き込み先の先頭は atomic で 1 回だけ取る。グループ同士の順番は早い者勝ちだが、64 個ずつのまとまりは保たれる。
    - 描く順番を大きく崩すと GPU が遅くなることがインスタンシングの調査で分かっているので、順番を保つようにした。
    - Wave 命令は使わない (FXC / Shader Model 5.1 に戻った時も動くように)。

  Culled バッファの並び :
    [DrawData × 65536][描画ごとの引数 × 65536][カウンター 2 個][詰めた引数 × 65536] (詰めた引数は 256byte 境界から)

■ 計測結果 (RTX 2070 / Release / --stress 10000 = 20002 オブジェクト / ExecuteIndirect + GPU カリング)
  各 2 回計測 (2 回の差は 0.001〜0.003 ms)
                                              描画数 (GPU)       詰め直しなし   詰め直しあり
    格子の中から  インスタンシングなし           20002 → 4996      0.137 ms       0.115 ms   (-16%)
    格子の中から  インスタンシングあり            1252 → 398       0.106 ms       0.105 ms
    全体が映る    インスタンシングなし           20002 → 20002     0.203 ms       0.205 ms
    全体が映る    インスタンシングあり            1252 → 1252      0.200 ms       0.202 ms

  正直なまとめ :
    - 効果が出るのは「空になる描画が多い」時 (インスタンシングを使わない / 違うメッシュが多い場面で、大半が映らない時)。
    - インスタンシングを使うと空の描画は元々少なく (1252 個中 854 個)、差は測れない程度。
    - 全部映る場面での負担 (コンピュートを 1 回多く実行する分) も測れない程度。
    - なので、GPU カリングを使う時は常に詰め直す (切り替えは用意しない)。

■ 確認したこと
  - D3D12 デバッグレイヤーのエラー・警告なし (Debug / インスタンシングあり・なし / 通常起動)。
  - 格子の中からのカメラで、前回 (詰め直しなし) と同じ見た目。プロファイラーの Draw calls (GPU) = 4996 (インスタンシングなし)。

■ 表示
  - プロファイラー : 「Draw calls (GPU)」(詰め直した後に実際に描いた数) を追加。Visible (GPU) は映ったオブジェクトの数。
  - 終了時のサマリーログの draws は、GPU カリング中は詰め直した後の数。
