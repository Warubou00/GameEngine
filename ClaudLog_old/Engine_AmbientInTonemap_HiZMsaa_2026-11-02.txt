 最適化 : 環境光 × 遮蔽 をトーンマップで足す / Hi-Z を MSAA の深度から直接作る
 日付   : 2026-11-02
 ブランチ : feature/ambient-in-tonemap (develop f740256 から)
====================================================================

■ 概要
  1. Forward + SSAO : 「環境光 × 遮蔽」をトーンマップの中で足すようにした
     以前は SSAO の後に全画面のパス (PSApplyAmbient) で HDR に加算してからトーンマップしていた
     → HDR の読み書き (加算のブレンド) が 1 回減る。MSAA では 4 / 8 サンプル分の書き込みが減る
  2. MSAA : Hi-Z (オクルージョン) を MSAA の深度から直接作れるようにした (CSDownsampleMS)
     以前は Hi-Z の前に必ず 1 サンプルの深度へ解決 (全画面のパス) していた
     計測の結果、直接作るのは「4x 以下」かつ「前のフレームで深度を読んでいない (SSAO なし)」時だけにした
  見た目は変わらない (動かない所は以前と最大 1/255 の差。半透明のキャラクターも同じ明るさ)

■ 1. 環境光 × 遮蔽 をトーンマップで
  - PSTonemap : g_Params[1].x = 1 なら、HDR に「環境光 (g_Inputs[0].y) × 遮蔽 (g_Inputs[0].z)」を足してから露出・トーンマップ
  - 半透明の扱い : 環境光を後で足すので、半透明の後ろの物の環境光が半透明の上に足されてしまう
    → 半透明も環境光の RT を描画先にして、覆った分だけ減らす (PSForwardAlphaSplit)
      RT1 のブレンド : 0 × 自分 + 環境光 × (1 - α)
      ScenePass.ForwardSplitAmbient + 半透明で、この PSO になる
  - ssao.shader の PSApplyAmbient は残した (自作のパイプライン用。組み込みの Forward は使わない)
  - C# : RenderPipeline.Tonemap(cmd, hdr, settings, ao, ambient) / ForwardRenderPipeline の SSAO の流れを変更

■ 2. Hi-Z を MSAA の深度から
  - hiZ.shader : CSDownsampleMS (段 0 で 2x2 × サンプルの一番奥を取る)。CSDownsample と本体は共通の関数
    (msaa をリテラルで渡すので、使わない方の読み方とテクスチャはコンパイルで消える)
  - Hi-Z のルートシグネチャ : 深度のテーブルに t1 (Texture2DMS) の範囲を重ねた (同じディスクリプタを MSAA として読む)
  - いつ直接作るか (CommandContext::hiZFromMsaa)
      ・4x 以下 (HIZ_FROM_MSAA_MAX_SAMPLES)。8x では解決してから作る方が速かった
          SSAO なし : 8x 直接 0.413 / 解決 0.369 ms
      ・前のフレームで全画面のシェーダーが深度を読んでいない時 (SSAO があると、どうせ解決するので先に解決する方が速い)
          4x + SSAO : 直接 0.443 / 解決 0.426 ms
          (MSAA の深度をコンピュートで読むと、深度の圧縮の展開が別に起きると考えられる)
        今のフレームの後のことは RHI には分からないので、前のフレームで決める (切り替えた次のフレームから合う)

■ 確認
  - Debug (D3D12 デバッグレイヤー有効) で D3D12 のエラー / 警告 0
      Forward : SSAO あり / なし × AA なし / FXAA / MSAA 2x / 4x / 8x、Deferred、負荷テスト (MSAA 2x)、リサイズ (MSAA 4x)、
      F2 / F4 / F5 / F6 の切り替え (Hi-Z の作り方が SSAO の ON / OFF で切り替わる)
  - MSAA から直接作った Hi-Z でも、映った数が MSAA なしと同じ (負荷テスト ground : 1010)
  - 動かない所の画素の差 : AA なし / MSAA 4x とも、以前と最大 1/255 (平均 0.013)
  - 半透明のキャラクター (PMX) : 以前と同じ明るさで、後ろの地面の環境光が透けて足されていない

■ 制限
  - Hi-Z の作り方は前のフレームで決めるので、SSAO を切り替えた最初の 1 フレームだけ遅い方になる (結果は同じ)
