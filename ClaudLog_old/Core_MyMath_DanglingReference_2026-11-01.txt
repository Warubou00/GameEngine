■ 問題
  ほぼ全ての関数が、計算結果を参照 (const float& / const Vector3& / const Color& など) で返していた。
  返していたのは関数内の一時オブジェクトなので、関数を抜けた時点で破棄されており、
  受け取った値はすでに無効なメモリを指していた (未定義動作)。

      const float& Length(const Vector2& vec)
      {
          return sqrtf(vec._x * vec._x + vec._y * vec._y);   // ← 一時オブジェクトへの参照を返す
      }

  コンパイラは C4172「ローカル変数またはテンポラリのアドレスを返します」を 20 件以上出していた。
  Debug ビルドではたまたまスタックが残っていて正しい値に見えることが多く、
  Release ビルドや呼び出しの間に別の関数を挟んだ時に壊れるので、見つけにくい種類のバグ。

■ 修正
  - 戻り値の型を全て「値」に変更 (const T& → T)。
      MyMath.h : 124 か所 (うちテンプレート Min / Max / Clamp / Pow / Abs / SingleLerp の 6 か所)
      MyMath.cpp : 118 か所
    引数の const T& はそのまま (参照で受け取るのは問題ない)。
    float / Vector2〜4 / Color は小さいので値で返してもコストはほぼ無い (RVO が効く)。
  - Min / Max / Clamp は引数への参照を返していたので一見安全だが、
    Clamp(x, 0.0f, 1.0f) のように一時値を渡すと同じくダングリングになるため、値返しにそろえた。
  - ColorMonocrome : 0.587 に f が抜けていて double で計算されていた (C4244) のを修正。
  - 呼び出し側は「値を受け取る」形 (float length = Length(v); など) だったので変更不要。
  - ファイルを Shift-JIS → UTF-8 (BOM付き) に変換。
    ヘッダーの先頭に「戻り値は値で返す」理由をコメントで残した。

■ 確認
  - Core / Renderer / RHI : Debug|x64, Release|x64 ビルド成功。C4172 は 0 件、MyMath の警告も 0 件。
  - C# ホストで起動 → 描画 → 正常終了を確認 (全項目 RHI_RESULT_SUCCEEDED)。

■ 未対応 (気づいた点)
  - Engine/Math/math.cpp に同じ内容の古いコピーがあり、同じバグを含んでいる。
    Engine プロジェクトは元々ビルドが通らない (レビュー 4章) ので今回は触っていない。
    Engine を直す時に、Core の MyMath を使うようにしてコピーを削除するのが良い。
  - Core/Source/Math/hash.cpp(46) : size_t → int の縮小変換 (C4267)。未定義動作ではないので今回は対象外。
