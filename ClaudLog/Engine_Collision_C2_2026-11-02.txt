■ 概要
  - 重なった組ごとに接触の情報を求めるようにした (法線 A → B / めり込み量 / 接触点 最大 4 つ。点ごとに法線)
    物理 (P1) はこれで押し戻す。C# からは engine.Physics.GetContacts で読める
    以前 (C1) は「重なっているか」だけだった
  - レイキャスト (engine.Physics.Raycast) / 重なりの問い合わせ (OverlapSphere / OverlapBox)。BVH の木をたどって答える
  - メッシュコライダー (動かない物だけ) : engine.Assets.LoadCollisionMesh(model) → Collider.FromMesh(mesh)
    見本の岩を箱からメッシュにした (rock.obj は岩 3 つの塊なので、箱だと岩の間の隙間にも当たっていた)
  - 見本 : 接触点を黄色の印 + 法線 (X キー)、レーザーのレイキャスト (当たった所に印と法線)

■ Physics.dll
  contacts.*   : 接触の情報 (Collide)
                 球 / カプセル どうし : 芯 (点 / 線分) の一番近い点どうし。平行なカプセルは重なる範囲の両端も
                 箱と球             : 箱の中の一番近い点。中心が箱の中なら一番近い面から押し出す
                 箱とカプセル        : 線分の上で箱に一番近い点 (黄金分割で探す)。寝ていれば両端も。
                                       芯が箱に刺さっていたら分離軸 (箱の 3 軸 + 線分 × 箱の軸) で一番浅く抜ける向き
                 箱どうし            : 分離軸 15 本で一番浅い軸。面なら相手の面を参照面の 4 辺で切り取り、
                                       めり込んだ点を最大 4 つ。辺どうしなら 1 点。わずかな差では面を優先 (点が飛ばない)
                 メッシュと球 / カプセル / 箱 : 重なる三角形ごとに求め (三角形の BVH)、同じ所の点はまとめ、深い 4 点を残す
                                       箱は分離軸 13 本。三角形の表へ押し出す向きを少し優先 (継ぎ目で引っかからない)
  raycast.*    : 球 (2 次方程式) / 箱 (ローカルでスラブ) / カプセル (円柱 + 両端の球) / メッシュ (Möller-Trumbore)
                 始点が形の中なら当たらない (Unity と同じ)。木は近い当たりが見つかったら、それより遠い枝をたどらない
  meshShape.*  : TriangleMesh (形。同じモデルの体で共有) / MeshInstance (体ごとのワールドの三角形と BVH)
                 動かない物なので、作った時 (と動かされた時) だけ作る
  dynamicTree  : レイでたどる RayCast を追加
  physicsWorld : 重なっている組の接触を表に持つ (動いていない組は前の接触のまま)。離れたら消す
  C ABI 追加   : Physics_CreateMesh / DestroyMesh / Raycast / RaycastBatch / OverlapSphere / OverlapBox / GetContacts
                 BodyDesc の詰め物だった所をメッシュのハンドルにした (96byte のまま)

■ Renderer
  - モデルの位置とインデックスを CPU 側に残すようにした (衝突判定のメッシュ用。1 頂点 12byte + インデックス 4byte)
    以前は GPU へ送った後に CPU 側のメッシュを全部捨てていた
  - Renderer_GetModelGeometry (数を聞いてから写す)

■ C#
  Physics.cs        : Raycast / OverlapSphere / OverlapBox / GetContacts (結果は Entity で返す)、ShowContacts、
                      RaycastHit / Contact (record struct)
  Assets            : CollisionMesh / AssetManager.LoadCollisionMesh (同じモデルは 1 回だけ)
  Collider          : ColliderShape.Mesh / Collider.FromMesh
  CollisionSystem   : メッシュのハンドルを送る / 接触点の表示
  見本              : LaserDemoSystem (レイキャスト)、X キー (接触点)、回る箱が地面に潜らない高さに

■ 計測 (Release / 1 フレームの Step の時間 ms)
  条件は C1 と同じ (球と箱を N 個、まっすぐ動かして壁で跳ね返す)
                                C1 (重なりだけ)       C2 (接触の情報)
    1,000 個 (BVH)              0.30〜0.46            0.24〜0.39
    10,000 個 (BVH)             5.1〜5.3              5.4〜5.9   (形の判定 0.21〜0.28 → 0.53)
    10,000 個 (グリッド)        3.1〜3.2              3.4〜3.6
    10,000 個・5% 動く (BVH)    0.83〜0.87            0.88〜0.91 (1 ms 未満のまま)
  形の判定が約 2 倍 : 接触点を作るのと、接触の表 (unordered_map) に入れる分。C3 で詰める候補
  レイキャスト (Physics_RaycastBatch。ばらまいた球 / 箱 / カプセルの中で、ばらばらの向きのレイ 1 万本)
    1,000 個の中 (長さ 25 まで)    : 1 本 1.8 µs
    10,000 個の中 (長さ 54 まで)   : 1 本 3.7 µs

      C2 のテスト 33 項目すべて OK
        接触 : 球-球 (法線の向き・深さ・点) / 箱の上の球 / 中心が箱の中の球 / 箱の上の箱 (4 点) / 回した箱 (4 点) /
               箱の辺と面 / 横に並んだ箱 (順番を入れ替えると法線が逆) / 寝たカプセル (2 点) / 立ったカプセル (1 点) /

        レイ : 一番近い物 / レイヤー / 始点が中 / 届かない / カプセルの横と上 / 回した箱の角 / メッシュの表と裏 / 外れ
