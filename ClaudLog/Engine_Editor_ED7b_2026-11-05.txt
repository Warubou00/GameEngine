■ 拡張の API (GameEngine.Editor の EditorExtensions.cs。public)
  [CustomEditor(typeof(T))] + ComponentEditor<T>
    OnInspectorGUI(ref T) : インスペクターを自分で描く。変えたら true (エディターが書き戻し、元に戻せる)。DrawDefaultInspector で既定の物も描ける
    OnDrawGizmos(Gizmos, T) : このコンポーネントを持つ全部の物で毎フレーム / OnDrawGizmosSelected : 選んだ物だけ
  [EditorWindow("メニュー/名前")] + EditorWindow : OnGUI に ImGui で描く。メニューで開く / 閉じる
  [MenuItem("メニュー/名前")] : 引数の無い static メソッド。メニューの一番上の名前が無ければ作る (Game など)
  [AssetImporter(".拡張子")] + AssetImporter : Assets に置いた / 書き換えた時の OnImport、ダブルクリックの OnOpen、Project のタイルの文字と色
  Gizmos : Line / Circle / WireSphere / WireBox / Label (ワールドの位置で。シーンビューに ImGui の線で描く)。Gizmos.Rgba で色
  EditorApi : Engine / World / Assets / Selected / CameraPosition / CameraForward /
              CreateEntity(name, position, setup) (元に戻せる) / Modify<T>(entity, change) (元に戻せる)
  拡張の中の例外は止めて Console (とインスペクターの赤い字) に出す (エディターは止めない。同じ物は 1 回だけ)

■ 見本の拡張 (Project/Scripts/Editor)
  SpinEditor.cs : Spin のインスペクター (速さのスライダー / Reverse / Stop / 1 回りの時間)、選んだ物に回る向きの輪と矢印と文字
                  OrbitMover : 全部の物の回る道 (水色の輪)
  GameTools.cs : 窓 Game > Game Stats (ゲームのコンポーネントの数、全部の Spin を止める : 元に戻せる) /
                 メニュー Game > Create Spinning Box (カメラの前に回る箱 : 元に戻せる) /
                 取り込み .palette.txt (1 行に「名前 #RRGGBB」→ 同じフォルダに「名前.material.json」を作る / 直す)

■ 途中で直したこと : 読み直すたびに古い Game.dll / GameEditor.dll が残り続けた
  原因 : AssemblyLoadContext の子のクラスのフィールドに、読んだ Game.dll を持っていた (GameEditor.dll から Game を探すため)。
         これで捨てた AssemblyLoadContext が解放されなかった (4 回読んで 4 つ残った)
  直し方 : フィールドに持たず、Load の中で Assemblies (その中に読んだ物) から探す → 4 回読んで 1 つ (今の物) だけ
  調べ方 : 一時的な調べ (拡張の機能を 1 つずつ止める / 前半のファイルに 1 つずつ戻す / 残っている Game.dll の数を数える) で絞った。調べのコードは消した
  あわせて : 確認の側 (EditorTest) が古い型を持つと解放されないので手放す / 古い GameEditor.dll も型の一覧から外す (ComponentRegistry.Forget)
  自動の確認に「何回読み直しても古い Game.dll が残り続けない」を足した
