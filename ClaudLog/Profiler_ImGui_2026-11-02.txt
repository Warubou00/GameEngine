 ImGui の組み込みとプロファイラー
 日付   : 2026-11-01 〜 2026-11-02
 ブランチ: feature/imgui-profiler (develop から作成)
================================================================================

■ 概要
  - リポジトリ直下に置いてもらった ImGui (1.91.0 WIP) を RHI.dll に組み込んだ
  - DX12 用バックエンド (imgui_impl_dx12.cpp/.h) が入っていなかったため、ユーザーの了承を得て
    公式リポジトリ (ocornut/imgui の v1.91.0 タグ, MIT ライセンス) から取得して ImGui フォルダに追加した
    (このバックエンドは 2022-10 以降変更されておらず、WIP 版の本体とそのまま組み合わせられる)
  - ImGui のウィンドウでプロファイラーを表示。F1 キーで表示 / 非表示
  - C# 側でウィンドウのタイトルに出していた FPS を削除 (タイトルは固定)

■ 確認
  - Core / RHI / Renderer : Debug|x64, Release|x64 ビルド成功 (警告なし。ImGui のソースも含む)
  - C# ホストで起動 → プロファイラー表示 → F1 で非表示 → 正常終了 を確認 (スクリーンショットで目視)
  - 修正後の最終版の見た目 : ユーザーが目視で確認済み (2026-11-02)
  - D3D12 デバッグメッセージの転送が有効な状態でエラー/警告 0 件
  - 表示例 (RTX 2070, 1280x720, VSync OFF, Debug)
      約 900 FPS / CPU フレーム 約 0.8 ms (内 ImGui 約 0.4 ms) / GPU 合計 約 0.02 ms
      描画 2 回 / 44 三角形 / VRAM 約 208 MB / 7.07 GB
  - モデルの読み込みは安定時 12〜21 ms で、ImGui を入れる前と同じ
    ※ビルド直後の 1 回目だけ 90〜150 ms になることがあった。DDS ファイルの読み込みに時間がかかっていて、
      直後に連続で計測すると再現しないので、ビルド直後のディスクの混雑 (リンカーの書き出しや、
      新しい DLL のウイルススキャン) による揺れと判断した。ImGui による低下ではない


--------------------------------------------------------------------------------
1. 構成
--------------------------------------------------------------------------------
  ImGui は RHI.dll の中だけで使う
    ImGui はグローバルな状態 (コンテキスト) を持つため、複数の DLL から使うと DLL ごとに別の状態になる。
    Renderer など RHI の外からは、公開インターフェイスの次の関数で操作する:
      SetProfilerVisible / IsProfilerVisible
      ReportProfilerValue(name, value) : 任意の値をプロファイラーの「Values」欄に出す
                                         (今は Renderer が "LoadModel (ms)" と "Draw items" を出している)

  新規ファイル
    RHI/Source/Profiler/frameStats.h    : 1 フレーム分の計測値
    RHI/Source/Profiler/debugUI.h/.cpp  : ImGui の初期化 / 入力 / 描画
    RHI/Source/Profiler/profiler.h/.cpp : プロファイラーのウィンドウ
    RHI/Source/DirectX12/Object/dx12_gpuTimer.h/.cpp : GPU の時間の計測 (タイムスタンプクエリ)
    ImGui/imgui_impl_dx12.cpp/.h        : 公式の DX12 バックエンド (v1.91.0)

  入力
    C# (WinForms) のウィンドウのメッセージ処理をネイティブ側でサブクラス化し、ImGui に渡す。
    C# 側の変更なしでマウス / キーボードが効く。終了時は元のメッセージ処理に戻す。
    F1 はサブクラスの中で直接見ているので、非表示中も効く。

  描画
    - シーンを描いた後、同じフレームのコマンドリストに ImGui の描画命令を積む
    - フォントのテクスチャはシーンと同じ SRV ヒープに 1 枠確保 (描画中にヒープを切り替えない)
    - ImGui の PSO は深度無しで作られているので、ImGui を描く前に描画先をバックバッファだけにする
    - 非表示の時は ImGui の処理を丸ごと省く (負荷ゼロ)


--------------------------------------------------------------------------------
2. プロファイラーの表示内容
--------------------------------------------------------------------------------
  概要   : FPS とフレーム時間 (0.5 秒ごとの平均 / 最小 / 最大)、GPU 名、画面サイズ、VSync / テアリング
  グラフ : CPU のフレーム時間 / GPU の時間 (直近 240 フレーム)
  CPU    : Frame / Wait (表示待ち + FrameContext の完了待ち) / Record scene / UI (ImGui) / Present
  GPU    : Total / Scene / UI (ImGui)
           タイムスタンプクエリで計測。結果は FRAME_COUNT フレーム後、そのフレームの完了待ちの直後に読む
           (CPU は GPU を待たない。表示は 2 フレーム遅れ)
  Draw   : 描画回数 / 三角形数 / オブジェクト数
  Memory : VRAM の使用量と予算 (IDXGIAdapter3::QueryVideoMemoryInfo。0.5 秒ごとに問い合わせ)
           このフレームのアップロード量 / リングバッファの使用量
  Values : RHI の外から ReportProfilerValue で渡された値


--------------------------------------------------------------------------------
3. 既存コードの変更
--------------------------------------------------------------------------------
  - CommandContext : GPU タイマー、計測値 (待ち / Present / 描画数 / 転送量)、
                     GetFrameCommandList / BindBackBufferWithoutDepth / MarkGpuSceneEnd を追加
  - UploadManager  : 送った量 / リングの使用量を返す関数を追加
                     (転送が無いフレームは 0 にする。最初の版では前回の量が残って表示されていたので修正)
  - RenderHardwareInterface : フレーム時間 / シーンの記録時間 / UI の時間を測り、ImGui を描く
  - Renderer       : 読み込み時間と描画リストの数をプロファイラーに渡す
  - C# (RHI.cs)    : タイトルバーの FPS 表示と計測用の Stopwatch を削除
  - プロファイラーのウィンドウは中身に合わせて自動で大きさが変わる
    (最初の版は固定サイズで、下の項目が切れていたので修正)


--------------------------------------------------------------------------------
4. 補足
--------------------------------------------------------------------------------
  - ImGui のウィンドウの位置は実行フォルダの imgui.ini に保存される (bin の中なので git 管理外)
  - ImGui フォルダには元から DX11 用のバックエンドも入っているが、ビルドには含めていない
  - 次の候補
      * CPU の区間を名前付きで積み上げる仕組み (ScopedTimer と連動して、任意の処理をプロファイラーに出す)
      * プロファイラーから VSync の切り替えなどの設定を変更できるようにする
