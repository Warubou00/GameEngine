==========================================================================
(コードは G1 と同時に書いた。ここでは G2 の項目の確認と、確認中に足した物をまとめる)

--------------------------------------------------------------------------
1. 見た目の機能 (ParticleEmitter)
--------------------------------------------------------------------------
 - 出す場所の形 : Point / Sphere (体積で均一) / Shell / Box / Disc (面積で均一)。出す向きは Transform の回転 × Direction の円錐
 - 動き : 速さ・寿命の範囲、重力、空気抵抗 (指数で弱める)、乱れ (位置と時刻で揺れる sin の場)、回転
 - 見た目 : 色と大きさを寿命で変える (線形の HDR。1 を超えると光る)、形 (丸 / 火花 / 輪)、速度の向きに伸ばす (StretchScale)
 - 重ね方 : 加算 / 半透明 を 1 つの PSO (乗算済みアルファ) で描く。加算は α = 0 を出して後ろを消さない
 - 発生 : Rate (端数は持ち越す) + Burst (1 回だけ)。動くエミッターは前のフレームの位置との間に散らして出す。
          フレームの中で生まれた時刻も散らす (Age = 乱数 × dt。同じフレームの物が層にならない)
 - ResetTrail() : 瞬間移動させた時に、前の位置との間に出さない (花火で使用)

--------------------------------------------------------------------------
2. エミッターを外した時 (資料 p.87 の対策)
--------------------------------------------------------------------------
 - ParticleSystem は ComponentPool.Removed で外されたことを知り、その番号を「寿命の最大 + 0.25 秒」使い回さない
   (出た物は生まれたエミッターの番号で重力などを読むため)。その間も位置・動かし方は送り続け、出す数だけ 0 にする
 - 外して値を写して付け直した物 (古い番号を持ったまま来る) は、番号の持ち主 (Entity) が違えば新しい番号にする
 - 確認 : --scene particles --view fountain で J (外す) → 生存数 約 15.5 万 → 約 8.3 万 (噴水の 7 万個が寿命で消えた)、
          水は寿命まで落ち続けて消える (scratchpad/g2j_t49.png)。J をもう一度で付け直して噴き出す (g2sw_t8.png)

--------------------------------------------------------------------------
3. Forward / Deferred / MSAA
--------------------------------------------------------------------------
 - Forward : 不透明の後に UpdateParticles、半透明の後に HDR だけを描画先にして DrawParticles
             (SSAO ありの時も HDR だけ。光る物に遮蔽を掛けない / 環境光の RT には書かない)
 - Deferred : G-Buffer の後に UpdateParticles (G-Buffer の深度で跳ねる)、半透明の後に HDR へ
 - MSAA : 描く PSO は描画先のサンプル数に合わせる。深度は 1 サンプルへ解決した物をシェーダーが読む (C++ が自動で解決)
 - 更新の後、C++ は深度を描画先に付け直すので、C# は続けて半透明を描ける
 - 確認 (Debug、エラー 0) : --scene particles / --pipeline deferred / --aa msaa4 / 実行中に F2 (Forward ⇔ Deferred)、
   F6 ×3 (FXAA → MSAA 2x → 4x → 8x)、J ×2 → 全部表示される (g2_sceneparticles_t7.png / g2_sceneparticlespipelinedeferred_t7.png /
   g2_sceneparticlesaamsaa4_t7.png / g2sw_t8.png)
