エディター ED4 : シーンの編集 2026-11-05
ブランチ : feature/editor-ed4

■ 目的 (ロードマップ ED4)
  選ぶ / ギズモ / 作る・消す・複製・親を変える / 元に戻す・やり直す / 再生・一時停止・1 フレーム・停止
  確認 : 「物を置いて動かし、保存して開き直すと同じ」「再生して止めると元に戻る」「元に戻すが全部の操作で効く」

■ 使い方 (エディター)
  シーンビュー
    左クリック : 選ぶ (モデルの三角形 + 物理の Collider。近い方)。何も無い所で選択を外す
    選んだ物 : 橙の箱 (モデルの形の箱) とギズモ
    W / E / R : 移動 / 回転 / 拡大縮小 (上のボタンでも)。World / Local の切り替え。Snap (Ctrl を押しながらでも)
      移動 0.5 m / 回転 15 度 / 拡大縮小 0.1 刻み。真ん中の四角 : 移動は画面の面で、拡大縮小は全体
    F : 選んだ物が収まる所へカメラを動かす (Hierarchy でダブルクリックでも)
    Play / Pause / Step / Stop (Ctrl+P)。再生中は枠が橙。再生中はシーンのカメラで見る (Game Camera / Editor Camera で切り替え)
  Edit メニュー : Undo (Ctrl+Z) / Redo (Ctrl+Y, Ctrl+Shift+Z) / Duplicate (Ctrl+D) / Delete (Del)
  GameObject : Create Empty / Create Empty Child
  タイトルと メニューの横 : 保存していない変更があると * 、再生中は [Playing] / [Paused]
  GameEngine.Editor.exe --editor-test : 自動の確認 (下)

■ 仕組み
  元に戻す (UndoStack.cs)
    - 変更は「前の値 → 後の値」を ED1 のシリアライズ (JSON) で持つ。エンティティは EntityInfo.Id (GUID) で覚える
      (消して戻すと番号 (Entity) が変わるため。参照している値も GUID で書いてあるので、戻すと新しい番号に繋がる)
    - ComponentEdit : コンポーネント 1 つ (値 / 足す / 外す。名前と有効 (EntityInfo) も)
      戻す時は今の値に「保存する値」だけを書き戻す (C++ のハンドルなど保存しない値はそのまま)
    - EntitiesEdit : 作る / 消す / 複製 (子を含めた JSON)。消した物を参照していた外のコンポーネント (Joint の相手など) も
      消す前の値を覚えて、戻した時に繋ぎ直す
    - CompoundEdit : 親を変える (Transform が無ければ付ける + 親の値) を 1 回の操作に
    - ドラッグ中 (インスペクターの数値 / ギズモ) は同じ相手の変更を 1 つにまとめる (ImGui の何かを触っている間 / ギズモを掴んでいる間)
    - 選んでいる物も Id で覚えるので、元に戻す / 停止の後も同じ物が選ばれる。消して戻すと戻った物がまた選ばれる
    - 保存した時の「一番上の変更とまとめた回数」を覚えて * を出す (元に戻して保存した時の状態に戻ると * が消える)
  再生 / 停止 (EditorApp.Edit.cs)
    - 再生 : シーン全体を JSON にして覚え、engine.IsPlaying = true (ゲームの System / 物理 / 音が動く)。元に戻すの記録は止める
    - 停止 : World を消して JSON から作り直す (アセットは AssetManager が覚えているので読み直さない)
    - Step : 1 フレームだけ IsPlaying を立てる (物理は固定の時間刻みなので、1 フレームでは進まないことがある)
    - 再生中に動かす System : 今は見本の SpinSystem / OrbitMoverSystem を Program で登録 (ED7 でゲームの DLL から自動に)
  選ぶ (SceneTools.cs の Picker)
    - モデルの形 (位置 / 三角形) を C++ から 1 回だけ写して覚え (AssetManager.GetModelGeometry を追加)、
      光線をモデルのローカルへ移して 箱 → 三角形 (Möller–Trumbore) で当てる
    - 物理の Raycast も当てて近い方 (形の無い Collider だけの物も選べる。見本の周回する球など)
  ギズモ (SceneTools.cs の Gizmo) : ImGui.NET に ImGuizmo が入っていないので自分で書いた (ImGui の線で描く)
    - 移動 : 軸の直線とマウスの光線の一番近い所 / 真ん中は画面の面
    - 回転 : 画面の上で中心の周りを回った角度 (軸がこちらを向いているかで向きを合わせる)。掴んだ時の軸を使い続ける
    - 拡大縮小 : 軸の上の距離の比 / 真ん中は左右のドラッグ
    - 親があれば、ワールドの値を親から見たローカルの値に直して書く。Static な物も行列を作り直させる (MarkDirty)

■ 変更 (ランタイム)
  SceneSerializer
    - Save(world, entities) : 一部のエンティティだけを書く (外の物への参照も Id で書く)
    - SaveComponent / LoadComponent : コンポーネント 1 つの値 (LoadComponent は今の値に書き戻す)
    - FindEntity(world, id)
    - 読む時、ファイルに無い Id は World に今ある物から探す (一部だけの JSON / 複製で外の物を指す参照)
    - 書く時、表に無いエンティティの Id は World から引く (コンポーネント 1 つを書く時に全部の物の表を作らない)
  AssetManager.GetModelGeometry (モデルの形を写す)
  World.Clear : 後ろから消す (以前は前から消していたので、読み直したシーンの番号が逆順になり、Hierarchy の並びが逆になった)
  ※ C++ は変えていない

■ 変更 (エディター)
  UndoStack.cs (新規) / SceneTools.cs (新規 : SceneCamera / Picker / Gizmo) / EditorApp.Edit.cs (新規 : 操作と再生) /
  EditorTest.cs (新規) / EditorApp.cs (ツールバー / 選ぶ / 箱 / ギズモ / ショートカット / Edit メニュー / タイトル) /
  Inspector.cs (変更を元に戻せるように。値を書く時に Transform の行列を作り直させる (以前は Static な物が動かなかった) /
  配列の値は写しを書き換える (以前はその場で書き換えていたので、元に戻す記録の「前の値」まで変わった)) /
  Program.cs (ゲームの System の登録 / --editor-test)

■ 途中で直したこと
  - 消した時に選択の Id も消していたので、元に戻しても選ばれなかった → Id は覚えたまま
  - ツールバーの最後のボタンの SameLine でシーンの画像が横に並んだ → NewLine
  - タイトルを毎フレーム Window.Text (Win32) で比べていた → 自分で覚えた文字列と比べる
  - 「元に戻して保存した時の状態」でも * が付いたまま → 一番上の変更とまとめた回数で比べる
  - 停止で Hierarchy の並びが逆 → World.Clear を後ろから

■ 確認
  自動 (--editor-test, showcase シーン) : 33 / 0 (Release と Debug。Debug は D3D12 の検証でエラー / 警告なし)
    作る→戻す→やり直す (同じ Id) / 戻すと * が消える / ドラッグが 1 つにまとまる / 動かした親に子が付いてくる /
    子ごと消す→戻すと親子も戻る / 選択が戻る / 複製 (子も。新しい Id。中の参照は複製どうし) / 親を変える (ワールドの位置はそのまま。輪は拒否) /
    消した物を参照していた Joint が戻すと繋がる / コンポーネントを足す・外す・値 / 全部戻すと元のシーンと同じ /
    再生で System が動く / 一時停止 / 1 フレーム / 停止で元に戻る / 選択が残る / 再生中の変更は記録しない /
    置いて動かして保存 → 開き直すと同じ / 選ぶ (11 個中 7 個が真ん中を通る光線で当たる。残りは他の物の陰) / 空は何も選ばない
  見た目 (エディターの窓だけを撮った。入力は PostMessage)
    - クリックで箱を選ぶ → 橙の箱とギズモ、インスペクター
    - 赤い矢印をドラッグ → X に 3.06 m 動いた (Static の箱も動く)。Undo 1 (Edit Transform)、タイトルに *
    - Ctrl+Z → 0, 0, 0 に戻った
    - E → 回転の輪。緑の輪をドラッグ → Y に -76.5 度 (マウスに付いてくる向き)、Undo 1
    - physics シーンで Play → 剛体 72 個が動く (シーンのカメラ、橙の枠)。Stop → 浮いていた箱も元の位置に戻った
  既存 : --hierarchy-test 18 / 0、--serialize-test 4 / 0

■ 速さ (Release, RTX 2070)
  エディターの C# update (平均) : 選んでいない時 0.103 ms (ED3 0.078 ms。回ごとの揺れの範囲) / 選んでいる時 0.178 ms
    (インスペクター / 箱 / ギズモの分 +0.08 ms。エディターだけの物で、ゲームの実行には入らない)
  再生 : シーンを JSON にする 0.3 ms (19 個) / 20〜25 ms (79 個、112 KB。最初の 1 回は JIT を含む)
  停止 : 作り直し 0.8 ms (19 個) / 6.9 ms (79 個)
  クリックで選ぶ : 0.02 ms / 回 (20 個。形は最初の 1 回だけ C++ から写す)

■ 残り
  - 複数を選ぶ / 範囲で選ぶ / ライトやカメラのアイコン (形の無い物はシーンビューで選べない。Hierarchy で選ぶ)
  - 選んだ物の輪郭は箱 (本当の輪郭線は GPU の ID バッファが要る)
  - Hierarchy の並びは番号の順 (兄弟の順番を持っていない。消して戻すと並びが変わることがある)
  - 再生中に変えたコンポーネントの値を残す機能 (Unity の Copy Component) は無い
