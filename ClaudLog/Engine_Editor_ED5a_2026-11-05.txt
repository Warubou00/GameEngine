■ プロジェクトのフォルダ (ユーザーの選択 : 新しく Project/Assets)
  CSharp_console/Project/Assets
    Models/  : 最初の 1 回だけ、見本の出力フォルダの Model (bin/x64/<構成>/Model) から写す (元のファイルは変えない。DDS キャッシュは写さない)
    Scenes/  : 見本のシーン (以前の CSharp_console/Scenes から移した。--resave-scenes でアセットの Id 付きに書き直した)
  git : .meta / *.scene.json / *.material.json だけを入れる。モデル / テクスチャ / 音の本体は .gitignore で外す
        (Tomimi など配布できない物を入れないため。.meta は入れるので、別の PC でも同じ Id になる)
  Release と Debug のエディターは同じ Project を使う (以前の bin/<構成>/Model は 85MB ずつ 2 つあった)

■ 使い方
  Project の窓 (下の Console / Stats と同じ所)
    左 : フォルダの木 / 右 : タイル (テクスチャは縮小画像、他は種類の色と名前) / 上 : 今のフォルダ (クリックで戻る)
    Import... : Assets の外のファイルを今のフォルダへ写す (OBJ は同じフォルダの .mtl とテクスチャも)
    New Folder / Show in Explorer / Refresh / 検索 (全部のフォルダから) / タイルの大きさ
    ダブルクリック : フォルダに入る / シーンを開く
    ドラッグ : モデル → シーンビュー (マウスの下の物の表面 / 地面 / 10 m 先に置く) / Hierarchy (原点、行の上なら子として)
              シーン → シーンビュー (開く)
              モデル / 音 → インスペクターのアセットの欄 (MeshRenderer.Model / AudioSource の音 / Collider.Mesh)
    置く / 落とすのも元に戻せる
  Explorer で Assets にファイルを置く / 消す / 名前を変えると、0.3 秒後に一覧が変わる (新しいファイルには .meta が付く)
  GameEngine.Editor.exe --project <folder> : 別のプロジェクト
  GameEngine.Editor.exe --resave-scenes : 全部のシーンを今の形式で保存し直す

■ 仕組み
  AssetDatabase (ランタイム。ゲームでも Id からパスを引けるように)
    - 「ファイル名.meta」(JSON : guid / kind) に Id。無ければ作る。フォルダにも .meta (Unity と同じ)
    - アセットのパスは "Assets/..." (/ 区切り、プロジェクトのフォルダから)。Id ↔ パスの表
    - Refresh : 全部を見回る。消えた物を外してから新しい物を足す / .meta ごと複製した物 (同じ Id が 2 つ) には新しい Id
    - 一覧に入れない物 : .meta / DDS キャッシュ (*.v1.dds) / . で始まる物
    - 以前の見本のパス "../Model/x" は Assets/Models/x にあればそちらに読み替える
  AssetManager.Database : 設定すると "Assets/..." のパスで読める (C++ には絶対パスを渡す。Model.Path はアセットのパスのまま)
  シーン : アセットは { "guid": ..., "path": "Assets/..." }。読む時は Id を優先 (動かした / 名前を変えたファイルも見つかる)
           Id の無い古いシーン / Database の無い見本 (GameEngine_console) は今まで通りパスで読む
  サムネイル : 別のスレッドで System.Drawing で読んで 96px に縮め、メインのスレッドで 1 フレーム 4 枚まで GPU へ (CreateUITexture)
  ファイルの見張り : FileSystemWatcher (別スレッド) は印だけ立て、最後の変化から 0.3 秒後にメインのスレッドで Refresh
