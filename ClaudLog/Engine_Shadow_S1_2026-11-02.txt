■ 概要
  - 太陽 (CastShadows の付いた最初の DirectionalLight) の影を付けた。Forward / Deferred / SSAO / FXAA / MSAA のどれとも使える
  - 影を落とす物 : 不透明 + 半透明 (アルファテスト。PMX のキャラクターも影を落とす)
  - 切り替え : F11 (影の ON / OFF)。--shadows on|off / --shadow-res N / --shadow-distance D
    C# : Graphics.Shadows (Enabled / Resolution 2048 / Distance 30 / NormalBias 1 / Softness 1)、DirectionalLight.CastShadows
  - 見本のシーンは太陽が高い (真上から約 36°) ので、影は短め (箱の右、岩の右、キャラクターの足元)

■ 仕組み (S2 のカスケードを見越した形にしてある)
  RHI
    1. 深度のレンダーターゲット (RenderTextureFormat.Depth32) : DSV で描き、SRV で読む (R32_TYPELESS)
       SetRenderTargets の depth に指定できる (以前はシーンの深度 SCENE_DEPTH だけ)
    2. 視点 : フレームの定数を「カメラ + 影のカスケード 4 つ」の 5 つの枠に書く (1 枠 768byte)
       DrawScene の Inputs[0] (C# の view 引数) で視点を選ぶ。影の視点の時は Root CBV をその枠に差し替えて描く
       (以前はフレームの定数がカメラの 1 つ (256byte) だけだった)
    3. 視点ごとの GPU カリング : 影の視点はライトの直方体で数える (視錐台だけ)。
       Culled バッファに今どの視点の結果が入っているかを覚えておき、カメラの描画が後で使う時は数え直す
       (以前は「1 フレーム 1 回、最初の不透明の DrawScene」でカメラの分だけ数えていた)
       Culled の状態も覚えるようにした (以前は 前段 = COMMON / 後段 = 読む状態 に決め打ち)
    4. ライトの行列は RHI がカメラに合わせて作る (Buffer::computeShadowViews。カメラ / ライト / 設定が変わった時だけ)
       - カメラの視錐台の [手前, Distance] を囲む球 → 正射影の大きさ (半径はカメラの向きに関係なく一定)
       - 球の中心をライトの視点のテクセル単位に丸める (カメラが動いても影の縁がちらつかない)
       - ライトの側へ 60 伸ばして、範囲の外にある物の影も拾う
       C# は設定とシャドーマップを渡すだけ (変わった時だけ P/Invoke : Renderer_SetShadowSettings)
    5. PSO : 影の PSO (ScenePass.Shadow) は深度だけ。不透明はピクセルシェーダー無し、半透明は PSShadowAlpha (α < 0.5 を捨てる)
       両面とも描く。傾斜バイアス 2.0
    6. ルートシグネチャ : 比較サンプラー s3 (線形・外は白)、テクスチャの配列を Texture2D<float> として読む範囲 (t0, space3) を重ねた
  シェーダー (hlslTemplate.shader)
    - shadowFactor : カスケードを選ぶ → 位置を法線方向に 1 texel 分ずらす (シャドーアクネ対策) → 3x3 の PCF (比較サンプラー) →
      Distance の最後の 10% で薄くする
    - shadeLights の中で、影を付けるライトにだけ掛ける (光が当たっている面だけシャドーマップを読む)
      → Forward (PSForward / PSForwardSplit / 半透明) とディファードのライティングの両方に効く
  C#
    - ShadowPass (Rendering/ShadowPass.cs。SsaoPass と同じ部品の形)。Forward / Deferred の最初に呼ぶ
    - LightSystem が影を落とすライトの番号を決める (C++ へ送るライトの並びの中の番号)

■ 途中で直したこと
  - Debug で D3D12 のエラー (負荷テストだけで出た) :
      "... is bound as DATA_STATIC_WHILE_SET_AT_EXECUTE ... had a change to a writable state ... required to be rebound"
    描画のルート SRV (DrawData) が Culled を指したまま、カメラのカリングが Culled を書き換えていた (影の視点で描いた後)
    → カリングの前に、ルート SRV を書き換えない入力のバッファへ付け替えるようにした

■ 確認
  - Debug (D3D12 デバッグレイヤー有効) で D3D12 のエラー / 警告 0 (上の修正の後)
      Forward / Deferred、SSAO あり / なし、FXAA / MSAA 4x / 8x、解像度 4096 + 距離 80、
      負荷テスト (ground / inside + Deferred / orbit + MSAA 4x)、リサイズ、F11 / F2 / F3 / F6 の切り替え
  - 映った数 (プロファイラー) が影なしと同じ (34 / 45、負荷テスト 1010 / 4996) : カメラのカリングの数え直しが正しい
  - 影あり / なしの画像の差 : 箱・岩・キャラクターの足元に影、キャラクターのフードの下に影。縞 (アクネ) は見当たらない

■ 制限 / 次 (S2)
  - カスケードは 1 つ (Distance までを 1 枚で)。S2 で 2〜4 段 (Texture2DArray) にして、遠くと近くの両方をくっきりさせる
  - S2 で比べること (ロードマップ) : 段の数と解像度 / 段ごとのカリング / 1 回で全段を描く / 遠い段の更新の間引き /
    動かない物のキャッシュ / 画面の影を先に 1 枚に作る (スクリーンスペースのシャドーマスク)
  - MSAA 4x + SSAO の時だけ影の増え方が大きい (+0.17) 理由を S2 で調べる
  - 点光源の影は無い (S3 の候補)
