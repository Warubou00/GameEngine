■ RenderSettings (コンポーネント。シーンに 1 つ。GameObject > Render Settings で作る / 選ぶ)
  Path (Forward / Deferred) / LightingModel / AntiAliasing / AmbientColor / BackgroundColor / Exposure / Tonemapper / Gamma /
  Ssao (Enabled / Radius / Intensity / Bias / SampleCount / ResolutionScale) /
  Shadows (Enabled / Resolution / Distance / NormalBias / Softness / CascadeCount / SplitLambda / CascadeBlend) /
  Fxaa (Subpixel / EdgeThreshold / EdgeThresholdMin) / Particles (Enabled / Capacity / Sorting / Collision / CollisionThickness / SoftDistance / HalfResolution)
  既定の値は engine.Graphics の既定と同じ (置いただけでは見た目は変わらない。見た目で確かめた)
  以前は engine.Graphics をコードで設定するだけだった (見本は起動の引数とキーで切り替えていた)

■ Volume (コンポーネント。GameObject > Volume (Box) / Volume (Global))
  範囲 : Global / Box (Transform の位置と回転、Size × 拡大縮小) / Sphere (半径 Size.X)。外側 BlendDistance の間でだんだん効く
  Weight / Priority (小さい物から混ぜ、大きい物が勝つ)
  上書きできる値 (Override... を付けた物) : Exposure / AmbientColor / BackgroundColor / SSAO の濃さ / 影の距離
  選ぶとシーンビューに範囲 (緑) と混ざり始める所 (薄い緑) を描く

■ RenderSettingsSystem (エンジン組み込み。カメラの後、描画パイプラインの前)
  最初の有効な RenderSettings を元に、カメラの位置で効く Volume を混ぜ、前のフレームに書いた値と違う物だけ engine.Graphics へ書く
  - 値が同じなら書かない : キーやコードで変えた値は、設定かカメラの位置が変わるまでそのまま (見本のキーの切り替えも動く)
  - 元の RenderSettings のエンティティが替わった時 (シーンを開いた時) は全部を書き直す
    (最初は値が同じなら書かなかったので、コードで変えた値が開き直したシーンでも残った。確認で見つけて直した)
  - RenderSettings も Volume も無いシーンでは何もしない (前のシーンにあった時だけ既定の値に戻す)
  - Path が変わったら ForwardRenderPipeline / DeferredRenderPipeline を作り直す

■ ProjectSettings (プロジェクトのフォルダの ProjectSettings.json。Edit > Project Settings)
  Time : FixedDeltaTime / MaxFixedSteps
  Physics : 重力 / SubSteps / Iterations / RelaxIterations / 接触と関節の固さ / 速さの上限 / 眠り / WorkerCount (-1 = 自動)
  Layers : 32 個のレイヤーの名前 / 衝突の表 (名前の付いたレイヤーどうしを三角のチェックの並びで)
  値を変えるとすぐ engine へ書き (Apply)、触り終わったらファイルに書く。既定の値は今までのエンジンの既定と同じ (ファイルが無くても今まで通り)
  ※プロジェクトの設定の変更は元に戻せない
  インスペクター : Collider.Layer はレイヤーの名前から選ぶ ([Layer])、CollideWith は名前のチェックの並び ([LayerMask])
