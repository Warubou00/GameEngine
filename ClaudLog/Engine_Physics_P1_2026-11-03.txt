■ 概要
  - Rigidbody コンポーネントを Collider と一緒に付けると、Physics.dll が固定の時間刻みで動かす
    以前 (C1〜C3) は衝突判定だけで、物を動かすのは C# (Transform) だけだった
  - 汎用性のために入れた物
      Dynamic / Kinematic、質量 / 慣性 (形と大きさから) / 減衰 / 重力の倍率 / 軸の固定 (Unity の Constraints)
      力の API (AddForce / AddTorque / AddForceAtPosition。ForceMode 4 種) / Velocity / MovePosition / MoveRotation
      摩擦 / 反発 / トリガー (Collider に持つ。動かない地面にも付けられる)
      IFixedSystem (Unity の FixedUpdate。固定の刻みで呼ばれる System)
      ジョイント : Joint コンポーネント (2 つの体 / 体とワールドの点。ジョイントだけのエンティティも可。壊れる力)
                   C++ は Joint を継承して Prepare / WarmStart / Solve を書けば新しい種類を足せる (joints.h)
      解き方の設定 : engine.Physics.Solver (重力 / 小さな刻みの数 / 接触の硬さ / 少し先の接触の距離 など)
  - 描画は前後の刻みの間を補間する (Interpolate。描画のフレームが 60 Hz と違ってもカクつかない)
  - 剛体もジョイントも IFixedSystem も無い間は、以前と同じく毎フレーム衝突判定だけ (C3 の動きのまま)

■ 解き方 (solver.cpp。Box2D v3 の「柔らかい小さな刻み」(soft step) を 3 次元にしたもの)
  1 回の Simulate(dt) :
    1. キネマティックの目標 → 速度 (MovePosition。着いたら止まる)
    2. 重なりを調べる (C3 の組の表のまま)。剛体の組は形を 2 cm 太らせて求め、少し離れた点も入れる
       (ぶつかる直前から止め始めるので、すり抜けと着地の震えが減る)。前の点に近い点は前の力積を引き継ぐ
    3. 接触の準備 : 点ごとに法線 / 摩擦 2 本の向き、有効な質量、回転の項 (慣性の逆数 × 外積) を 1 回だけ求める
    4. dt を 4 つに分けて、それぞれで
         速度を進める (重力 / 力 / 減衰) → 前の力積をかけ直す → 解く (めり込みを「ばね + ダンパー」で戻す) →
         位置を進める → 解く (速度だけ。戻しすぎた勢いを取る)
       接触の離れ具合は、小さな刻みごとに体の動きから見積もり直す (形の判定は 1 回だけ)
    5. 反発 (始めにぶつかった速さから。1 m/s より遅い時は跳ねない) / 力積を組の表に残す
    6. 動いた剛体の形と箱を作り直す (SetTransforms と同じ道。木の葉も)
  並列 : 接触を「同じ動く体を触らない組」に色分けし (Box2D v3 の graph coloring。最大 24 色、あふれた分は順番に)、
         色ごとに並列に解く。結果はスレッドの数に関係なく同じ (テストで確認)
         ワーカーは仕事の後 100 µs 回して待つ (ParallelFor が 1 刻みに約 100 回来るので、毎回起こすと遅い)

■ ジョイント (joints.cpp)
  Distance : 2 点の距離。Min〜Max の限り (片側の拘束) + Hertz > 0 ならばね。Min == Max で Hertz 0 なら硬い棒
             Joint.Distance / Joint.Rope (伸びる限りだけ) / Joint.Spring
  Ball     : 2 点を合わせる (3x3 の有効な質量)
  Fixed    : Ball + 向き (作った時の qB qA^-1 を保つ)
  BreakForce を超えると壊れる (IsBroken。もう働かない)。繋いだ 2 つの体どうしは押し戻さない (CollideConnected で変更)
  体を消す / 作り直すと C++ では壊れた扱い。C# の Joint は体ができ直した時に作り直す

■ 制限 / 次 (P2 の候補)
  - 眠り (止まった物は解かない) と島 (触れ合っている物のまとまり) : 止まった山の時間をほぼ 0 にする (一番効く)
  - ヒンジ (扉 / 車輪) / スライダー / モーター / 角度の限り (ラグドール) などのジョイント
  - 速い物のすり抜け (CCD) : 今は少し先の接触 2 cm と、速度の上限だけ (細い物を速く撃つと抜けることがある)
  - 重ねて作った物 (深く重なった物が多い) は押し戻しで飛び散ることがある (押し戻しの速さは 3 m/s まで)
  - メッシュは動かない物だけ (動く剛体には球 / 箱 / カプセルを使う)。転がり抵抗は無い (球は AngularDamping で止める)
  - Update でかけた力は、すぐ後の 1 刻みだけかかる (Unity と同じ。続けてかける力は FixedUpdate で)
