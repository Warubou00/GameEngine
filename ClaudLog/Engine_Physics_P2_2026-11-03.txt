■ 概要
  - 毎刻み、起きている動く剛体を「接触 / ジョイント」で繋いだ島にまとめ、島の全部の体が 0.5 秒止まっていたら島ごと眠らせる
  - 眠った物は、解かない / 位置を進めない / 木も形の判定も触らない / C# へ状態を送らない / Transform に書かない
    (組の表と接触と前の力積は残すので、起きた時はすぐに安定した状態から始まる)
  - 起きる : 動いている物が触れた (この刻みで初めて触れた物も) / 力・速度・目標などの命令 / Transform で動かした /
             支えていた物が消えた・動かされた / ジョイントの相手が起きている / 剛体の値を変えた
  以前 (P1) は止まった山も毎刻み全部を解いていた (箱 1,000 個の山で 1 刻み 約 5 ms)

■ 結果 (Release。--physics-bench N : 箱を N 個積んだ山が止まった後)
                                解く時間 / 刻み        重なり / 刻み          C# の合計 / フレーム
    1,000 個  眠りなし (P1)     4.9 ms                1.04 ms                0.69 ms
              眠りあり (P2)     0.10 ms               0.23 ms                0.09 ms
    2,000 個  眠りなし (P1)     11.0 ms               1.72 ms                7.0 ms (1 フレームに刻みが 1 回以上)
              眠りあり (P2)     0.17 ms               0.32 ms                0.19 ms
  DLL のテスト (1,000 個を 10 段に並べて落とし、6 秒後から 1 秒) : 4.16 → 0.165 ms / 刻み。止まった位置は眠りなしと同じ (平均の高さ 1.9910)
  DLL の計測 (5,000 個の山) : 約 16 秒で全部眠る。眠る前 約 32 ms → 眠った後 0.39 ms / 刻み
  Debug の見本のシーン (--scene physics) : 265 → 574 FPS (止まった積み木が眠るため)
  衝突判定だけ (剛体なし。C3 の計測) : 変わらず (1 万個 1.72 ms / 5% 0.44 ms / 1,000 個 0.15 ms。眠りの処理は剛体が眠っている時だけ動く)

■ 作り (solver.cpp)
  島       : 起きている剛体を union-find でまとめる (接触 (少し先の点も含む) とジョイントで繋ぐ)。
             動かない物とキネマティックは島を繋がない (床に置いた別々の山は別の島)
  止まった : 重心の速さ + 回転で一番速く動く所の速さ (角速度 × 重心から一番遠い所) < 0.1 m/s、かつ角速度 < 2 rad/s
             (Box2D v3 と同じ測り方。基準は Unity の既定 (質量あたりの運動エネルギー 0.005 ≒ 0.1 m/s) と同じくらい)
  眠る     : 島の全部の体が TimeToSleep (0.5 秒) 以上止まっていたら、島ごと眠らせ、島に番号を付ける (起きる時は島ごと)
  起きる   : Simulate の始め (重なりを調べる前) と、重なりを調べた後の 2 回、眠った物に触れている組を見る
               - 起きている動く剛体 / 動いているキネマティックが触れている (接触の点がある) → 起こす
               - Transform で動かされた物は、太らせた箱が重なっているだけでも起こす (離れていく時も起こしたい)
             命令 (力 / 力積 / 速度 / 目標 / Wake) / SetTransforms で眠った物を動かした / 剛体の値を変えた / 体を消した (触れていた相手)
  眠らせる : Rigidbody.Sleep() (この体だけ。触れている物が動けば起きる)
  C# へ    : Physics_GetActiveBodyStates (起きている剛体 + この刻みで眠った剛体だけ)。眠った物は最後に 1 回だけ Transform に書く
  解く     : 起きている剛体だけ SolverBody にする。眠った物は動かない物と同じ扱い (起きている動く物が無い接触 / ジョイントは解かない)

■ 確認中に見つけて直した物
  1. 止まった山の中で、箱が 0.05〜0.1 m/s でゆっくりずれ続け (クリープ)、山が 1 つの島のまま眠れなかった
     原因 : 箱どうしの接触点の選び方。点が 5 つ以上ある時「一番浅い点と入れ替え」(入れた順で決まる) だったので、
            止まった箱 (深さがほぼ同じ) で刻みごとに選ぶ点が変わり、前の力積の引き継ぎが外れていた
     直し : 面積が一番大きくなる 4 点を残す (一番深い点 / そこから一番遠い点 / 三角形の面積が一番大きい点 / 面積が一番増える点。contacts.cpp)
            → 1,000 個の山が 6〜8 秒で全部眠るようになった (直す前は 30 秒たっても 955 個が起きていた)
  2. 眠った塔に速く飛んできた球は、動かない壁に当たったように跳ね返っていた (塔は眠ったまま)
     原因 : 起こすのを重なりを調べる前だけで行っていた (その刻みで初めて触れた物では起きない)
     直し : 重なりを調べた後にも、もう一度起こす (テストで、直す前は塔が動かない (0.01 m)、直した後は崩れる (16 m) ことを確認)
  3. 眠っているジョイントの力が 0 と報告された → 眠っている間は解かず、眠る前の力を残す
  4. 動かない台を Transform で動かすと、先に重なりを調べ直して接触が消え、上で眠っている箱が分からなかった
     → 起こすのを重なりを調べる前に移した (上の 2 と合わせて前後の 2 回)

■ C#
  Rigidbody : CanSleep (既定 true) / IsSleeping / WakeUp() / Sleep()
  engine.Physics.Solver : EnableSleep / TimeToSleep / SleepLinearVelocity / SleepAngularVelocity
  engine.Physics : AwakeBodies / Islands / IslandMs (プロファイラーにも出る)
  コライダーの線 : 眠っている剛体は青
  見本 : --physics-bench N --sleep off で眠りを切って比べられる

■ C++ (Physics.dll)

             SolverSettings 64 → 80byte (眠りの設定) / PhysicsStats 64 → 80byte (AwakeBodies / Islands / IslandMs)

■ 制限 / 次
  - 大きな島 (5,000 個が触れ合った山) は、どれか 1 つが揺れていると島全体が起きたまま (島の全部が止まる必要がある)。
    5,000 個の山は約 16 秒で眠ったが、その間は 1 刻み 30 ms 以上かかる
    (山の上の端で 2 点だけで支えられた箱がシーソーのように小さく揺れ続けていた。基準 0.05 m/s では眠らず、0.1 m/s で眠る)
  - メッシュと箱の接触点は、まだ「一番浅い点と入れ替え」のまま (岩の上の箱がずれ続けることがあれば、同じ直しを入れる)
  - 次の候補 : ヒンジ・角度の限り・モーター / 速い物のすり抜け (CCD) / 大きな島を分けて眠らせる
