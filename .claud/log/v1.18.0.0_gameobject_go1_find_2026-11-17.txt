■ 作った物
- Runtime/Ecs/GameObject.cs (新) : readonly struct (World + Entity)。Unity の GameObject に当たる窓口
  Name / Tag / CompareTag / Layer / ActiveSelf / ActiveInHierarchy / SetActive / ref Transform / ref GetComponent<T> / TryGetComponent /
  HasComponent / ref AddComponent / RemoveComponent / Parent / GetChildren / FindChild("子/孫") / Destroy
  static : Find / FindWithTag / FindGameObjectsWithTag / FindObjectOfType<T> / FindObjectsOfType<T> (SceneManager.Current の World)
  if (go) で生きているか。Entity と暗黙に行き来できる。コンポーネントのフィールドに書け、保存は相手の Id (Entity と同じ)
- Runtime/Ecs/World.Find.cs (新。World を partial にした)
  Find(名前 / "A/B/C" / "/A/B") / FindAll / FindWithTag / FindAllWithTag / FindById / FindObjectOfType<T> / FindObjectsOfType<T>
  GetName / SetName / GetTag / SetTag / CompareTag / Reindex。既定は有効な物だけ (includeInactive で無効も)
  索引 (名前 / タグ / Id の辞書) は最初に探した時に作り、EntityInfo の入れ物の Added / Removed / Replaced で少しずつ直す
  ref で直接書き換えられた名前は、見つけた時に確かめて捨てる (間違った物は返さない)。Reindex で直せる
- ComponentPool : internal の Replaced イベント (SetBoxed / World.Set で丸ごと置き換えた時)。SetBoxed と World.Set は共通の Set を通す (動きは同じ)
- タグ : EntityInfo.Tag (string。null = Untagged) + [Tag] 属性 + ComponentField.IsTag + ProjectSettings.TagNames (Header "Tags")
  シーンに "tag" を書く (Untagged は書かない。以前のファイルはそのまま読める)。EntityTags.Untagged
- SceneSerializer : GameObject の書き方 / 読み方。FindEntity(Guid) は索引で引く (無ければ今まで通り順に見る)。Id を付けた時に Reindex
- SceneManager : internal World (GameObject.Find 用)
- Behaviour<T> : GameObject (今の物) / Find / FindWithTag / FindGameObjectsWithTag / FindObjectOfType<U> / FindObjectsOfType<U>
- エディター
  Inspector : 名前の下の Layer の横に Tag の一覧 (Project Settings の TagNames。一覧に無いタグもそのまま出す)。[Tag] の string も同じ一覧
              GameObject のフィールドは今の Entity と同じ一覧から選ぶ (Hierarchy から落とせる欄は GO2)
  名前を ref で書き換えていた所を SetName に (Hierarchy の名前の変更 / 複製の (copy) / プレハブの名前の反映)。UndoStack の Id を付ける所は Reindex
