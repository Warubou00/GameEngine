■ 依頼
「GO2 へ進む」 : 設計の GO2 = Inspector の Entity / GameObject のフィールドを Unity の ObjectField のようにする

■ 作った物
- GameEngine.Editor/Inspector.ObjectField.cs (新。Inspector を partial にした)
  - 欄 : [ 名前 (GameObject) ][...] ラベル。何も無ければ None (薄い字)、消えた物は Missing (赤)
  - Hierarchy の行を落とす (ENTITY の荷物。ドラッグしている物は EditorApp から受け取る)。断る物は落としても入れず、理由をツールチップに出す
  - クリック = Ping / ダブルクリック = 選ぶ / 右クリック = Ping・Select・Clear
  - [...] = 選ぶ窓 : 検索 (名前の一部・大文字小文字を問わない / t:型 / tag:タグ)、None、ImGuiListClipper で見えている行だけ描く、親の名前、
    無効な物は薄い字、断る物は押せない (理由はツールチップ)。[...] の下に右端を揃えて出し、背景は不透明
  - 以前の Entity の欄 (全部の物を並べるコンボ) は消した (この欄に置き換え)
- GameEngine.Editor/EditorApp.ObjectRefs.cs (新)
  - Ping(entity) : Hierarchy を出し、親を開き、その行までスクロール (1 回)、1.5 秒かけて消える黄色い枠
  - ReferenceRefusal : 編集中に別のシーン (足したシーン / サブシーンの中 ⇔ メインシーン) の物を断る。再生中は断らない
- EditorApp.cs
  - Hierarchy の行の前後で Ping の処理を呼ぶ
  - ドラッグを始めたら、押した時に変えた選択を元に戻す (以前は押した物が選ばれたままで Inspector がドラッグ中の物に変わり、落とす先の欄が消えた)
  - Inspector に PingEntity / SelectEntity / DraggedEntity / ReferenceRefusal を渡す
- 確認 : EditorTest.Objects.cs に objectFields (選ぶ窓の一覧 / 値の型 / 別のシーンを断る / Ping / 欄から選ぶ窓を開く / Missing) と
  objectFieldsDrag (Input.Simulate で本当の ImGui のドラッグ & ドロップ : GameObject の欄 / Entity の欄 / 親は変わらない / 選択が保たれる / Undo 2 回)
  撮影用 : --editor-test-section objects-view (Ping と選ぶ窓を開いたまま待つ)
- Docs/Reference/template.html : 「Inspector の物の欄 (v1.19)」。index.html は作り直した
