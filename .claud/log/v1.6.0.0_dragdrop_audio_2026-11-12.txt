4. GetComponent<AudioSource>() の Play() で鳴らない (SoundTest.scene.json) … 修正

■ 原因
3. Stop は World.Clear() → AudioSource が外れたボイスを「次の AudioSystem の更新で削除」に予約する。
   ところが AudioSystem.Update は再生中 (IsPlaying) しか呼ばれないため、予約が実行されず鳴り続けた。
4. SoundController が「AudioSource audioSource = GetComponent<AudioSource>();」でフィールドに保存していた。
   AudioSource は struct なのでコピーになり、Play() はコピーの Request を書き換えるだけで本物に届かなかった。

■ ドラッグ & ドロップの決まり (Unity と同じ)
- 写す (元のファイルはそのまま)。同じ名前があれば "名前 1"
- フォルダは中身ごと (PMX とテクスチャのフォルダなど)。OBJ は今まで通り .mtl とテクスチャも一緒に写す
- .meta / 隠しファイル / DDS キャッシュは写さない (Id は新しく付ける。同じ Id が 2 つにならないように)
- 自分の中へフォルダを写すことはできない。Project の窓の外へ落とした時は Console に案内だけ出す
- エディターを管理者として動かしていると、Windows (UIPI) がエクスプローラーからのドロップを通さない

■ AudioSource の注意
- コピーから届くのは Play() / Stop() / IsPlaying だけ。Volume / Loop などの書き換えは ref で行う
  (ref var a = ref GetComponent<AudioSource>(); a.Volume = 0.5f;)
- 一時停止中の音はこれまで通り鳴り続ける (止めるのは Stop だけ。一時停止の API は C++ 側に無い)
