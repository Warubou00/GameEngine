v1.10.0.0 : プロファイラーの強化 P1 (窓を 5 つに分ける / クリックのすり抜けを直す / CPU の区間)
ブランチ : feature/v110-profiler-windows (未コミット)
日付 : 2026-11-15

■ 依頼と対応 (設計の P1)
1. 1 つだけのプロファイラーを複数の窓に分ける … 対応
   - View > Analysis : Profiler (概要。F1) / CPU Usage / GPU Usage / Rendering Stats / Memory
   - どれもエディターの ImGui の窓 (ドッキングできる)。以前の Stats の窓の中身は Profiler の「Editor」の欄へ移した
   - 履歴 300 フレーム。グラフをクリック / ドラッグでそのフレームを選んで止める (全部の窓がそのフレームを出す)
     Pause / Latest / Clear
   - Profiler       : FPS (0.5 秒の平均 / 最小 / 最大)、GPU の名前、画面 / VSync / Tearing、パイプラインの説明、
                      CPU / GPU のグラフ、まとめの表、Editor の欄
   - CPU Usage      : CPU のフレームと C# の区間のグラフ、区間のタイムライン (横 = 時間、縦 = 入れ子) と表 (Total / Self / %)、
                      C++ の内訳 (待ち / 記録 / Present)、報告された時間 (… (ms))、Physics の値
   - GPU Usage      : GPU 合計 / シーンのグラフ、合計 / シーン / スキニング / GPU パーティクルの時間
   - Rendering Stats: 描画数のグラフ、ExecuteIndirect / Instancing / GPU culling / Occlusion の切り替え (以前は F1 の窓)、
                      描画数 / インスタンス / 三角形 / 物の数 / その他の値
   - Memory         : C# のヒープのグラフ、VRAM (使用量 / 予算)、メッシュのバッファ、アップロード、モデル / マテリアルの数、
                      .NET の GC、プロセスのメモリ

2. プロファイラーの上のクリックがエディターにすり抜ける … 対応
   - 原因 : プロファイラーは RHI.dll の中の別の ImGui のコンテキストで描いていた。ウィンドウのメッセージを横取りしていたが、
     ImGui_ImplWin32_WndProcHandler はマウスのメッセージにほぼ 0 を返すので、メッセージは WinForms → エディターの ImGui にも届き、
     エディターの ImGui はそこに窓があることを知らないので Hierarchy / Scene が反応していた
   - 直し方 : エディターでは F1 の窓 (オーバーレイ) を切り (F1 もメッセージの横取りもしない)、窓は全部エディターの ImGui で描く。
     C++ からは計測値だけを読む。同じコンテキストなので、窓の下には入力が届かない
   - Player (ビルドしたゲーム) は今まで通り F1 の窓

3. CPU の区間 (CPU Usage の窓のため) … 対応
   - GameEngine.Profiler.BeginSample / EndSample / using (Profiler.Sample("名前")) (入れ子。閉じ忘れはフレームの終わりで閉じる)
   - Engine.Run の各段とゲームの System ごと (型の名前) に区間を入れた
   - Profiler.Enabled が false の間は何もしない (CPU Usage の窓が開いている間だけ true。フレームの頭の値で 1 フレーム通す)

■ 性能
- CPU Usage の窓を閉じている間 : 区間は static の bool を見るだけ (1 フレームに 30 回ほど)
- 開いている間 : 区間ごとに Stopwatch を 2 回読む (区間は 1 フレームに 15〜30 個)。窓の描画 (ImGui) の分はエディターの GUI に入る
- 測った値 (Release、RTX 2070、エディターの中で 1000 回 / 100 万回の平均、2 回) :
    記録している間   : 75〜85 ns / 区間 (BeginSample + EndSample) → 1 フレーム 20 区間で 2 µs 程度
    記録していない間 : 6〜9 ns / 区間 → 1 フレーム 0.2 µs 程度
- C++ から読むのは窓が開いている間だけ (1 フレームに P/Invoke 2 回 + 0.5 秒ごとに文字列)。値の名前は増えた時だけ読む
