■ 依頼
「エディター利用者が独自に定義できる設定ファイル (int / float の他に List や GameObject などの参照も)。これを以て v2.0.0.0」
設計 UD1〜UD3 を承認。UD1 から。
「Unity / RE Engine のように Scene 上の参照は取れないようにしても構わない」→ シーンの物への参照は持てないことにした (設計から変えた点)

■ 決めたこと (設計から変えた点)
- シーンの物 (Entity / GameObject / ComponentRef<T>) は UserData に保存しない。書く時は null、読むと空。
  (設計では「シーンと物の Id で後から引く」案だったが、ユーザーの指示で Unity / RE Engine と同じにした。物を作る元はプレハブの参照で持つ)
- [Serializable] なクラス (と、そのリスト) も UserData の中に書ける (Unity と同じ。入れ子は 10 段まで)。
  シーンのコンポーネントの書き方は今まで通り (UserDataMode の時だけ)
