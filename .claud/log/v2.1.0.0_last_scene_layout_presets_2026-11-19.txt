■ 1. エンジンの修正 (§10 #10 : Behaviour<T> を 1 つでも使うと、動いた物が描画に送られない)
- 原因 : Behaviour<T> は全部 ILateSystem。Engine.Run は LateUpdate の後に _transformSystem.Update(World) を呼び、
  Update / 物理で立てた Transform.Changed を下ろしていた (行列は同じなので立て直さない) → RenderSyncSystem が何も送らない
- 直し : そこを UpdateAgain (keepChanged: true。剛体の後の計算と同じ) にした (GameEngine.Runtime/Engine.cs)
  TransformSystem.cs はコメントだけ
- 確認 : 直しを一時的に戻すと確認が FAIL (0 / 5 フレーム)、直すと PASS (5 / 5) になることを見た

■ 2. 前に開いていたシーン
- シーンを開く / 保存する / 名前を変えると、プロジェクトの Library/EditorState.json ({"LastScene": "Assets/..."}) に書く
  (Library は git に入れない。新しいプロジェクトの .gitignore にも Library/ がある。Unity も Library に覚える)
- Program.cs : --scene が無ければそのシーンを開く (ランチャーは --project だけを渡すので、ランチャーから開いた時も効く)。
  無い / Assets の外 / 壊れたファイルなら今まで通り showcase → Scenes の最初のシーン
- --editor-test / --quit-after では書かない (EditorApp.RememberLastScene = false)。--editor-test では読まない
- 確認 : EditorState.json に physics.scene.json を書いて --project ... --quit-after 60 で起動 → "[Editor] Last opened scene : Assets/Scenes/physics.scene.json"

■ 3. 窓の並びのプリセット (View > Layout)
- Default (既定の並び) + 登録した並び 5 つまで。選ぶとその並び + 窓を出すか (Hierarchy / Inspector / Console / Project / Profiler 系 /
  Render Graph Viewer / Frame Debugger) に戻る
- Save Layout... / Manage Layouts... → Layouts の窓 : 名前を付けて登録 (Save As New / Enter)、Load / Overwrite / Rename / Delete (2 回押す) / 上下
- 名前 : 日本語可、32 文字まで、前後の空白は取る。空 / 同じ名前 (大文字小文字を区別しない) / "Default" は断る (理由を窓に出す)
- 置き場 : %LOCALAPPDATA%\Tsumugi Engine\Editor\layouts.json (クラッシュレポートと同じフォルダ)。
  Package のエディターのフォルダは版を上げると消えるので、exe の隣 (editor_prefs.json / imgui.ini の所) には置かなかった。
  プロジェクトにも依らない (Unity の Layout と同じ)。書く時は .tmp に書いてから置き換える
- 読み方 : ImGui はフレームの途中で ini を読めないので、ImGuiBackend.LoadLayout で預け、次の NewFrame の前に LoadIniSettingsFromMemory
- View > Reset Layout は Default と同じにした (以前は docking だけ戻し、閉じた窓は閉じたままだった)
- フォント : 名前に使いそうな記号 (① ★ ※ → … ℃ Ⅱ ■ ♪ ㈱ など) が「?」で出ていたので、メイリオから記号の範囲も重ねた
  (GetGlyphRangesJapanese に入っていない。起動時に 1 回作るだけ)
