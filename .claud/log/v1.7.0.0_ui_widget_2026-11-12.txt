■ 依頼と対応
1. UE のように Widget アセットとして持ち、Scene と 1 対多 … 対応
   - Widget アセット (.widget.json。AssetKind.Widget)。基準の解像度 (既定 1920 x 1080) + 部品のツリー
   - シーンには UIWidget コンポーネント (Widget / ZOrder / Visible)。1 つのシーンにいくつでも、同じ Widget を別のシーンからも使える
     (作るたびに別の UUserWidget)。再生で出て、シーンを替える / 再生を止めると消える (UE の PIE / レベルの切り替えと同じ)
   - コードからも : UI.CreateWidget(path) → AddToViewport(z) / RemoveFromParent / IsVisible / SetZOrder / GetWidget<T>(name)
2. UI の部品は UE 相当 … 対応 (名前は UE の C++ と同じ U 付き : WinForms の Button などとぶつからない)
   Panel  : CanvasPanel (Anchors / Offsets / Alignment / AutoSize / ZOrder) / HorizontalBox / VerticalBox (Auto / Fill + FillWeight) /
            Overlay / UniformGridPanel / ScrollBox / SizeBox / ScaleBox / Border / WidgetSwitcher
   Common : TextBlock (折り返し / 揃え / 影) / Image / Button / ProgressBar / Spacer
   Input  : CheckBox / Slider / EditableTextBox (日本語の文字も可。Enter / フォーカスで確定)
   共通   : Visibility (Visible / Collapsed / Hidden / HitTestInvisible / SelfHitTestInvisible) / IsEnabled / RenderOpacity /
            RenderTransform (移動 / 拡大 / 回転) / Clipping
   イベント : OnClicked / OnPressed / OnReleased / OnHovered / OnUnhovered / OnCheckStateChanged / OnValueChanged /
             OnTextChanged / OnTextCommitted / OnUserScrolled (C# の event)
3. テストスクリプト (Widget の重ね表示 / on / off) … 対応
   Project/Scripts/UITest.cs + Assets/Scenes/ui.scene.json + Assets/UI/HUD / Menu / Popup.widget.json
     1 : HUD の on / off (コンポーネントの Visible)   2 : Menu の on / off (コードで IsVisible)   3 : Popup の on / off
     4 : コードで組んだトースト (z 30。アセットを使わない)   Z : Menu の重なり順 10 ↔ 30 (Popup の暗い背景の手前 / 奥)
     Menu : スコア +10 / タブ (WidgetSwitcher) / 箱を回す (CheckBox) / 速さ (Slider) / 名前 (EditableTextBox → HUD に出す) / 色 (UniformGrid)
4. Editor のバージョンアップ … Engine.props 1.7.0.0、Package を作り直し

■ しくみ (C++ は変えていない)
- 描画 : 四角を UIDrawList に積む。Player は Graphics.SubmitUI (ImGui と同じ C++ の UI のパス)、
  エディターは ImGui の描画のリストに足す (再生中のシーンビューの絵の上 / Widget Designer の中)。同じテクスチャ + 切り取りはまとめる
- 文字 : System.Drawing (Runtime で既に使っている) で Windows のフォントを文字の表に描く。大きさは 12〜128 px の決まった段
  (間は縮めて使う)。新しい文字はそのフレームの分だけ 1 枚の小さなテクスチャにして送る
  → C++ に UI のテクスチャを消す API が無いので、表を作り直さない / 拡大縮小で増えない作りにした
- 並べ方 : UE の Slate と同じ 2 回 (Prepass → Arrange)。変換は Matrix3x2 (RenderTransform / ScaleBox も同じ道)
  画面の大きさへは基準の解像度の短い方の辺に合わせて拡大縮小
- 毎フレーム : ゲームの System の後、エディターの GUI の前に UIManager.Update (UIWidget の反映 → 並べる → マウス / キー → 描く)
  マウスの当たりは手前の UserWidget から。Image / Border (色のある物) / ScrollBox / 押せる物が後ろへ通さない (UI.IsPointerOverUI)

■ 追加の修正 (2026-11-12) : showcase に空の物 + WidgetController.cs を付けて再生するとエディターが落ちる
原因は 2 つ
1. Widget の名前を変えると ".widget" が消えた (v1.7 の不具合)
   AssetDatabase.SplitName の「2 つ続きの拡張子」の表に .widget.json が無く、"New Widget.widget.json" の拡張子を ".json" と見ていた。
   名前を "SampleWidget" にすると "SampleWidget.json" (Text) になり、スクリプトの UI.CreateWidget("Assets/UI/SampleWidget.widget.json") が
   FileNotFoundException を投げた
2. ゲームのコードの例外を誰も受け取らず、エディターごと落ちた (UI に限らず、どのスクリプトの例外でも同じ)
修正
- GameEngine.Runtime/Assets/AssetDatabase.cs : SplitName に .widget.json を足す
- GameEngine.Runtime/Engine.cs : Engine.GameCodeException を追加。設定されていれば、衝突のメソッド / Update / FixedUpdate (物理) /
  LateUpdate / UI の更新 (クリックなどのイベント) の例外を受け取ってそこへ渡し、フレームを続ける。
  null (Player) は今まで通り投げる (Player はログと箱で理由を出して終わる)
- GameEngine.Editor/EditorApp.cs / EditorApp.Edit.cs : 例外を Console に赤で出し (型 / 内容 / 呼び出しの 12 行)、再生を一時停止する。
  Pause で続ける (Start で起きた物は呼ばれ直さない) / Stop で終える。GameCodeExceptionCount (確認用)
- GameEngine.Editor/EditorTest.cs : 名前を変えても .widget.json のまま / 無い Widget を読む System で、エディターが落ちずに一時停止する (+3 項目)
- Package/Project/SampleProject/Assets/UI/SampleWidget.json (+ .meta) を SampleWidget.widget.json に戻した (Id はそのまま。
  WidgetController.cs が読むパスと同じ)
確認
- MSBuild Editor Release x64 : エラー 0 (警告は既存の物のみ)
- --editor-test : pass 363 / fail 0
    PASS renaming a widget keeps the .widget.json extension
    [Error] Exception in game code : FileNotFoundException : Failed to load widget: Assets/UI/Missing.widget.json → [Editor] Paused ...
    PASS an exception in game code pauses the play instead of crashing the editor (calls 1, errors 1)
- make_package.py : 1 回目はランチャーが動いていて失敗。閉じてもらってから作り直し、成功 (57 s)。
