  設計の時の「サブシーンの中の物をメインシーンを開いたまま直接編集するか」は、おすすめの「見るだけ + そのシーンを開いて直す」にした (直接の編集は次の版)

■ 作った物 (GameEngine.Editor/EditorApp.Scenes.cs が中心)
- Hierarchy
  - SubScene を持つ物の後ろに [Sub Scene 名前 · active / standby / unloaded / loading 42%]
  - サブシーンの中の物は紫。Transform の無い物も持ち主の下に並べる
  - メインでない一番上のシーン (足したシーン / DontDestroyOnLoad / 非同期で読み込み中 (loading 90%)) は、枠の見出しの下にまとめる
    (1 つのシーンだけの時は今まで通り。物ごとにシーンを引かない速い道)
  - 持ち主の右クリック > Sub Scene : Load / Unload / Activate / Standby / Open
  - サブシーンの中の物の右クリック : 「Open Sub Scene '名前'」と「Select Owner」だけ
  - Project の .scene.json をドラッグ (空いた所 = 一番上 / 物の上 = 子) : SubScene を持つ物を作って読む (元に戻せる。開いているシーン自身は置けない)
- 編集中は、サブシーンの中の物は見るだけ (メインシーンに保存されないので、直しても残らないため)
  - 消す / 複製 / 親を変える / 子を作る / 名前 / ModifyComponent / ギズモ を止め、Console に 1 回だけ理由を出す
  - Inspector : 上に理由と「Open Its Scene」ボタン、欄は全部触れない (ImGui.BeginDisabled)
  - 再生中は触れる (止めると元に戻るのは他の物と同じ)
- Inspector の SubScene の下 : 状態 (Active / Standby / Unloaded / Loading)、物の数、Load / Unload / Standby・Activate / Open
- SubScene.Scene を変えた時 (Inspector / ModifyComponent / 元に戻す) : 読んでいる物と違えば外して読み直す
- シーンのアセットの名前を変えた時 : 開いているシーンの SubScene.Scene も付け替える (元に戻せる)
- 元に戻す / やり直す / 複製の後 : 戻った持ち主の LoadOnStart のサブシーンを読む

■ 直した物 (S1 / S2 の時からの問題)

  以前はサブシーンを持つ物を消す / 複製すると中の物まで JSON に入り、元に戻すとメインシーンの物として戻った (保存にも入った)
