■ 依頼
「Scene が Scene を複数持てる構造 (RE Engine 相当。スクリプトで Load / Unload (有効 / 無効化))」と
「Unity / UE に相当する Scene を切り替える機能」を、同期 / 非同期で動くように (ロード画面が作れる汎用性)。
設計 (S1〜S4) を報告し、「S1 から始めて」で S1 (実行時の土台 / 同期) を実装した。非同期は S2、エディターの表示は S3。

■ 作った物
- SceneManager (GameEngine.Runtime/Scenes/SceneManager.cs) : engine.Scenes / SceneManager.Current / Behaviour の Scenes
  - LoadScene(path, Single | Additive) : Single は今のシーンを外して読み、メインシーン (ActiveScene) にする
  - UnloadScene / GetScene(entity) / GetEntities(scene) / UnloadUnusedAssets
  - DontDestroyOnLoad(entity) : 永続シーン (Persistent, Id 1) へ移す (Transform の子 / 持っているサブシーンも一緒)
  - サブシーン : LoadSubScene(owner, active?) / UnloadSubScene / SetSubSceneActive / GetSubScene / FindSubSceneOwner / LoadStartSubScenes
  - イベント : SceneLoaded / SceneUnloading / ActiveSceneChanged
  - Scene (状態 Unloaded / Loading / Loaded、IsActiveSelf / IsActive、Parent / Owner / Children)
- SubScene コンポーネント (Components/SubScene.cs) : Scene (.scene.json) / LoadOnStart / ActiveOnLoad
  - 中の一番上の物 (親の無い Transform) は持ち主の子になる。持ち主を無効にする / 消すと、中も無効 / 外れる
  - 入れ子にできる。自分を読む輪は読まずに Console に出す

■ 仕組み (変えた所)
- EntityInfo.SceneId (internal。保存しない / インスペクターに出ない) : どのシーンの物か。0 = 今のメインシーンの物 (コードで作った物など)
- World : シーンごとの印 (Inactive / NotMain)、IsSelfActive (Active かつシーンが有効)、Clear の後の Cleared イベント
  - World.SetActive も、無効なシーンの物は有効にしない
- TransformSystem : 自分の有効 = EntityInfo.Active かつシーンが有効 (3 か所。配列を 1 回引くだけ)
- SceneSerializer
  - Load の中身を SceneLoader にした (Parse = World に触らない / Step = 1 回目で全部のエンティティを作り、その後 1 つずつコンポーネント)。
    同期の Load はこれを最後まで回すだけ (以前と同じ物を同じ順で作る)。S2 の非同期も同じ道を通る
  - Save(world) はメインでないシーン (サブシーン / 足したシーン / 永続) の物を書かない
- Engine
  - Scenes を作る。Engine.LoadScene は SceneManager に任せた (今まで通りすぐ読む。残す物が無ければ World.Clear して番号も 0 から = 以前と同じ)
  - フレームの頭 (全部の System の前) に Scenes.Update : ゲームのコードの中で頼まれた読み込み / 外すを行う、持ち主の消えたサブシーンを外す、持ち主の有効の変化を印に反映
  - 衝突のメソッド〜UI の間は Scenes.InGameCode = true (この間の読み込み / 外すは次のフレームの頭へ)
- エディター (最小限。表示は S3)
  - 停止 / スクリプトの読み直しで JSON から世界を作り直した後、LoadStartSubScenes(開いているシーン) でサブシーンを読み直す
    (S1 の途中で見つけた不具合 : 開いているシーンを登録しないと、自分を読む輪が見つからず、メインシーンが自分の中にもう 1 つ読まれた → 登録して直した)
